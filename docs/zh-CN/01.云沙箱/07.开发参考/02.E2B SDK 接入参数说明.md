# E2B SDK 接入参数说明

云沙箱数据面以兼容 E2B SDK 和 E2B CLI 为主，未提供独立的数据面 SDK。开发者接入数据面时，应继续使用 E2B SDK / CLI 的对象、方法和参数命名，只把鉴权和服务端点切换到云沙箱。Team、API Key、Quota 等资源管理能力属于控制面，可通过原生 OpenAPI、阿里云 SDK 或阿里云 CLI 调用，详情参见[阿里云 SDK & API 说明](04.阿里云%20SDK%20%26%20API%20说明.md)。

本文不替代 E2B SDK 官方类型定义。不同语言 SDK 的参数命名、默认值和单位可能不同，业务代码应以所使用 SDK 版本的类型定义为准；本文只说明接入云沙箱时必须关注的参数和兼容边界。

## 基础配置

使用 E2B SDK 或 E2B CLI 接入云沙箱时，至少需要配置 API Key、API URL 和域名。

```bash
export E2B_API_KEY="<your-api-key>"
export E2B_API_URL="https://api.<region>.e2b.fc.aliyuncs.com"
export E2B_DOMAIN="<region>.e2b.fc.aliyuncs.com"
```

其中 `<region>` 需要与云沙箱所在地域一致。当前支持的 `<region>` 包括 `cn-beijing`、`cn-shanghai`、`cn-hangzhou`、`cn-shenzhen`、`cn-hongkong`、`ap-southeast-1`、`us-east-1` 和 `us-west-1`。如果 API URL、域名、模板和 Sandbox 不在同一地域，常见结果是创建失败、连接失败或模板不可见。

API Key 应在函数计算控制台创建和管理，具体步骤参见[创建 API Key](../01.开始使用/03.创建%20API%20Key.md)。不要通过 E2B SDK 管理云沙箱 API Key，也不要把 API Key 写入代码仓库、日志、截图或前端页面。

## E2B CLI 配置

新版本 E2B CLI 使用 `E2B_API_KEY` 认证。`E2B_ACCESS_TOKEN` 是 E2B 已废弃的旧认证变量，不建议在新接入流程中使用。

如果 SDK 可以访问云沙箱，但 CLI 认证失败，优先检查 CLI 版本、`E2B_API_KEY`、`E2B_API_URL` 和 `E2B_DOMAIN`。

## Python SDK 常用参数

Python SDK 通常使用 snake_case 参数名：

- `api_key`：云沙箱 API Key，对应 `E2B_API_KEY`。
- `api_url`：云沙箱 API URL，对应 `E2B_API_URL`。
- `domain`：Sandbox 域名后缀，对应 `E2B_DOMAIN`。
- `template`：创建 Sandbox 使用的模板名称或模板 ID。
- `timeout`：Sandbox 生存时间，Python SDK 单位为秒；当前 SDK 创建默认300秒。FC的零值、最小值与各操作语义见[超时说明](../04.%E5%8A%9F%E8%83%BD%E8%AF%B4%E6%98%8E/01.%E6%B2%99%E7%AE%B1/07.%E8%B6%85%E6%97%B6.md)，不要套用原始 E2B REST 创建默认15秒。
- `envs`：创建 Sandbox 时注入的环境变量。
- `metadata`：写入控制面的自定义元数据，适合保存任务 ID、业务来源、Agent 类型等可索引信息。

示例：

```python
import os
from e2b_code_interpreter import Sandbox

sandbox = Sandbox.create(
    template="code-interpreter-v1",
    api_key=os.environ["E2B_API_KEY"],
    api_url=os.environ["E2B_API_URL"],
    domain=os.environ["E2B_DOMAIN"],
    metadata={"task_id": "task-001"},
    envs={"TASK_ID": "task-001"},
)

try:
    result = sandbox.commands.run("python3 -c \"print('hello from sandbox')\"")
    print(result.stdout.strip())
finally:
    sandbox.kill()
```

## TypeScript SDK 常用参数

TypeScript SDK 通常使用 camelCase 参数名：

- `apiKey`：云沙箱 API Key，对应 `E2B_API_KEY`。
- `apiUrl`：云沙箱 API URL，对应 `E2B_API_URL`。
- `domain`：Sandbox 域名后缀，对应 `E2B_DOMAIN`。
- `template`：创建 Sandbox 使用的模板名称或模板 ID。部分调用方式会把模板作为 `Sandbox.create()` 的第一个参数传入。
- `timeoutMs`：Sandbox 生存时间，单位为毫秒；与命令执行超时、请求等待超时分开。
- `envs`：创建 Sandbox 时注入的环境变量。
- `metadata`：写入控制面的自定义元数据。

示例：

```typescript
import { Sandbox } from "e2b";

const sandbox = await Sandbox.create("code-interpreter-v1", {
  apiKey: process.env.E2B_API_KEY,
  apiUrl: process.env.E2B_API_URL,
  domain: process.env.E2B_DOMAIN,
  timeoutMs: 10 * 60 * 1000,
  metadata: { task_id: "task-001" },
  envs: { TASK_ID: "task-001" },
});

try {
  const result = await sandbox.commands.run("python3 -c \"print('hello from sandbox')\"");
  console.log(result.stdout.trim());
} finally {
  await sandbox.kill();
}
```

## 参数使用建议

- 优先通过环境变量传入 `apiKey` / `api_key`、`apiUrl` / `api_url` 和 `domain`，避免在代码中写死地域和凭证。
- `metadata` 用于控制面查询、审计和业务关联，不会自动进入 Sandbox 运行环境。
- `envs` 用于 Sandbox 内进程读取，不应保存需要长期持久化的业务状态。
- 超时时间要按任务实际运行时长设置。过短会导致任务中断，过长会增加资源占用和费用风险。
- 任务完成后应主动调用 `sandbox.kill()`。仅已开通白名单的账号可在需要保留现场时使用暂停与恢复，不要把暂停当成默认释放资源方式。
- 迁移已有 E2B 应用时，先只替换 API Key、API URL 和域名；确认最小创建、命令执行、文件读写和资源释放链路通过后，再接入模板、Code Interpreter、元数据和环境变量等能力。

## 不作为接入参数的能力

以下能力当前不应写入云沙箱的默认 SDK 接入路径：

- 云沙箱 API Key / Access Token 管理：通过函数计算控制台完成，不通过 E2B SDK 管理。API Key 创建和管理参见[创建 API Key](../01.开始使用/03.创建%20API%20Key.md)。
- Volume、Team 管理：Volume 当前不属于云沙箱 E2B 兼容主路径；Team 请在函数计算控制台管理。
- Snapshot：已支持，使用说明参见[快照](../04.功能说明/01.沙箱/12.快照.md)。
- Metrics、Logs：字段或返回结果存在限制，生产监控和日志采集应使用 FC 对应服务。Network Config Update 支持限定的出站字段，详见网络访问控制。

完整能力边界参见[E2B SDK 兼容 API 清单](./01.E2B%20SDK%20兼容%20API%20清单.md)和[开始使用 / E2B 兼容说明](../01.开始使用/07.E2B%20兼容说明.md)。

## 三层参数命名

SDK 会序列化参数并补充默认值。Python/TypeScript 参数不能直接作为 HTTP JSON 字段使用；SDK 可选参数也不一定是原始 HTTP 的可选字段。

| 含义 | Python SDK | TypeScript SDK | E2B HTTP 字段 | 类型及说明 |
| --- | --- | --- | --- | --- |
| 平台凭证 | `api_key` | `apiKey` | `X-API-Key` header | 字符串；FC 的 API Key |
| 平台地址 | `api_url` | `apiUrl` | 请求 URL | FC 使用对应地域的 API URL |
| 沙箱域名 | `domain` | `domain` | 客户端路由配置 | SDK 接入配置，不是创建请求体字段 |
| 模板 | `template` | `Sandbox.create(template, options)` 首参 | `templateID` | HTTP 必需的字符串；SDK 可使用自己的默认模板 |
| 沙箱生存时间 | `timeout` | `timeoutMs` | `timeout` | Python/HTTP 为秒，TS 为毫秒；FC 边界见超时专题 |
| 请求等待超时 | `request_timeout` | `requestTimeoutMs` | 客户端请求配置 | 不是沙箱生存时间，也不是命令执行超时 |
| 环境变量 | `envs` | `envs` | `envVars` | 字符串到字符串的映射 |
| 沙箱元数据 | `metadata` | `metadata` | `metadata` | 字符串映射；不会自动变成进程环境变量 |
| envd 访问保护 | `secure` | `secure` | `secure` | 布尔值；SDK 默认开启，FC 省略时也默认开启 |
| 出网开关 | `allow_internet_access` | `allowInternetAccess` | 创建时 `allow_internet_access` | FC 创建接口还兼容 `allowInternetAccess` |
| 入站鉴权 | `network.allow_public_traffic` | `network.allowPublicTraffic` | `network.allowPublicTraffic` | 默认 true 表示公网 URL 无需流量令牌；false 要求令牌 |
| 出站允许列表 | `network.allow_out` | `network.allowOut` | `network.allowOut` | 字符串数组，支持 IP、CIDR、域名 |
| 出站拒绝列表 | `network.deny_out` | `network.denyOut` | `network.denyOut` | 字符串数组，仅支持 IP、CIDR |

自动暂停和自动恢复的 SDK 参数随版本演进，当前官方 SDK 使用 `lifecycle`，HTTP 使用 `autoPause`、`autoResume.enabled` 等字段。不要将 SDK 的 `lifecycle` 对象原样发送给 HTTP API。FC 的暂停/恢复开放条件仍以[暂停与恢复](../04.%E5%8A%9F%E8%83%BD%E8%AF%B4%E6%98%8E/01.%E6%B2%99%E7%AE%B1/06.%E6%9A%82%E5%81%9C%E4%B8%8E%E6%81%A2%E5%A4%8D.md)为准。
