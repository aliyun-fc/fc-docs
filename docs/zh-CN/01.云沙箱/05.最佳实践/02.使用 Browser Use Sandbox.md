# 使用 Browser Use Sandbox

> **访问说明**：`allow_public_traffic` 默认为 `True`，表示公网 URL **无需流量令牌**即可访问；设为 `False` 时所有公网请求必须携带 `e2b-traffic-access-token` 请求头，query 参数无效。`secure` 默认为 `True`，控制 SDK/envd 控制面鉴权，与流量令牌是两套独立令牌；示例省略默认的 `network` 参数，`secure=True` 为显式写出。公网 URL 应视为访问凭证：未设置应用层鉴权时，持有 URL 的人可完全控制沙箱内浏览器（含已登录态与 Cookie），请勿公开分享，也不要写入日志或前端代码。需要限制访问时，参见[配置公网访问鉴权](../04.功能说明/06.网络/01.访问沙箱/01.访问沙箱%20HTTP%20端口.md#配置公网访问鉴权)与[责任共担](../06.安全合规/01.责任共担.md)；受限 API Key 在 Enforce 模式下需具有 `sandbox.network.ingress`（Python SDK 只要传 `network` 就会附带发送 `allowPublicTraffic`，故必然置位；JS/TS SDK 与 REST 仅在显式设置 `allowPublicTraffic` 或 `maskRequestHost` 时才置位）与 `sandbox.network.egress`（SDK 默认发送 `allow_internet_access`）权限。受限模式下，服务端客户端可直接在 WebSocket 握手头携带 `e2b-traffic-access-token`（Playwright `connect_over_cdp(headers=)`、Puppeteer `connect({ headers })`、`browser_use` `BrowserSession(headers=)`、Python `websockets`、`wscat`）；只有运行在浏览器页面内的 WebSocket 客户端（如网页版 noVNC）无法自定义握手头，需由受控后端代理注入。

Browser Use Sandbox 面向需要访问网页、点击按钮、填写表单、截图归档或抓取动态页面的 Agent。推荐基于 [browser 模板](../04.功能说明/02.模板/07.其他模板/01.browser-模板.md) 创建沙箱：3000 端口提供 browser 服务，可通过 CDP 连接 Puppeteer、Playwright 或 BrowserUse。

如果任务只涉及网页访问、点击、截图、下载文件和轻量结果提取，使用 Browser Use Sandbox 即可。如果浏览器产物还需要在同一会话中交给 Python/Node.js 做数据清洗、表格分析或报告生成，优先使用 [AIO Sandbox](03.使用%20AIO%20Sandbox.md)。

## 适用场景

| 场景 | 说明 |
| --- | --- |
| 网页数据采集 | 访问动态页面，提取标题、正文、表格、链接或业务字段 |
| 运营后台自动化 | 登录后台，填写表单，点击按钮，下载报表或截图归档 |
| 页面巡检 | 定时打开页面，验证关键元素、截图、性能或可用性 |
| 轻量 E2E 测试 | 在隔离浏览器环境中运行端到端测试，避免污染 CI Worker |
| 浏览器工具型 Agent | 让 Agent 通过 BrowserUse 等框架完成多步骤网页任务 |

## 推荐流程

1. 按 [browser 模板](../04.功能说明/02.模板/07.其他模板/01.browser-模板.md) 构建业务模板，例如 `my-browser-template`。
2. 使用模板创建沙箱，并设置合理的超时时间。
3. 通过 `sandbox.get_host(3000)` 获取 browser 服务公网 host。
4. 轮询 `/health`，确认 browser 服务已经就绪。
5. 通过 `wss://<sandbox-host>/ws/automation` 连接 Puppeteer、Playwright 或 BrowserUse。
6. 执行网页访问、点击、输入、截图、PDF 生成或下载。
7. 将结构化结果、截图、HTML、PDF 或下载文件保存到沙箱任务目录。
8. 业务侧读取结果后销毁沙箱。

## 准备本地环境

以下示例使用 Node.js 和 Puppeteer Core。业务侧不需要安装完整浏览器，因为 Chromium/Chrome 已运行在 browser 沙箱中。

```json
{
  "name": "browser-use-sandbox-demo",
  "version": "1.0.0",
  "type": "module",
  "dependencies": {
    "e2b": "^2.31.0",
    "puppeteer-core": "^24.0.0"
  }
}
```

下文「BrowserUse 接入」的 Python 示例还需安装 Python 依赖：

```bash
pip install browser-use==0.13.10 e2b==2.31.0
```

该示例从环境变量读取配置：`E2B_API_KEY`、`E2B_API_URL`、`E2B_DOMAIN` 由 E2B SDK 读取（见[通过 SDK 使用云沙箱](../01.开始使用/03.快速入门/01.通过%20SDK%20使用云沙箱.md)）；`E2B_BROWSER_TEMPLATE` 可选，默认 `my-browser-template`；`DASHSCOPE_API_KEY` 为百炼 API Key，必填；`QWEN_MODEL` 可选，默认 `qwen-vl-max`。运行前先 `export` 这些变量，或用 `python-dotenv` 的 `load_dotenv()` 从 `.env` 加载。

## Puppeteer 示例

示例流程如下：

1. 创建 `my-browser-template` 沙箱。
2. 等待 browser 服务 `/health` 返回 200。
3. 通过 CDP 连接云端浏览器。
4. 打开 `https://example.com`，提取页面信息并保存截图。

```javascript
import { writeFile } from "node:fs/promises";
import puppeteer from "puppeteer-core";
import { Sandbox } from "e2b";

const TEMPLATE = process.env.E2B_BROWSER_TEMPLATE || "my-browser-template";

const BROWSER_PORT = 3000;
const TARGET_URL = "https://example.com";
const TASK_DIR = "/tmp/browser-task";
const SCREENSHOT_PATH = `${TASK_DIR}/browser-example.png`;

const sleep = (ms) => new Promise((resolve) => setTimeout(resolve, ms));

function toArrayBuffer(bytes) {
  return bytes.buffer.slice(bytes.byteOffset, bytes.byteOffset + bytes.byteLength);
}

async function waitUntilHealthy(sandbox, host, timeoutMs = 60_000) {
  const deadline = Date.now() + timeoutMs;

  while (Date.now() < deadline) {
    let result;
    try {
      result = await sandbox.commands.run(
        `curl -sS -o /dev/null -w '%{http_code}' -m 4 ` +
          `https://${host}/health`,
        { timeoutMs: 10_000 },
      );
    } catch (error) {
      result = error;
    }

    const code = (result.stdout || "").trim();
    if (code === "200") {
      return;
    }
    await sleep(2_000);
  }

  throw new Error(`browser 服务在 ${timeoutMs}ms 内未就绪`);
}

let sandbox;

try {
  sandbox = await Sandbox.create(TEMPLATE, {
    timeoutMs: 300_000,
    secure: true,
  });

  const host = sandbox.getHost(BROWSER_PORT);

  await sandbox.files.makeDir(TASK_DIR);
  await waitUntilHealthy(sandbox, host);

  const browser = await puppeteer.connect({
    browserWSEndpoint: `wss://${host}/ws/automation`,
  });

  const page = await browser.newPage();
  await page.setViewport({ width: 1365, height: 768 });
  await page.goto(TARGET_URL, {
    waitUntil: "networkidle2",
    timeout: 60_000,
  });

  const screenshot = await page.screenshot({ fullPage: true });
  await sandbox.files.write(SCREENSHOT_PATH, toArrayBuffer(screenshot));
  await writeFile("browser-example.png", screenshot);

  const result = await page.evaluate(() => ({
    url: location.href,
    title: document.title,
    text: document.body.innerText.replace(/\s+/g, " ").slice(0, 500),
  }));

  await browser.close();
  console.log(result);
} finally {
  if (sandbox) {
    await sandbox.kill();
  }
}
```

## BrowserUse 接入

对于以自然语言驱动网页操作的 Agent，可以让 BrowserUse 连接 browser 沙箱暴露的 CDP 地址。业务服务负责创建和销毁沙箱；BrowserUse 只连接这个沙箱中的浏览器会话。

```python
import asyncio
import os

from browser_use import Agent, BrowserSession, ChatOpenAI
from browser_use.browser import BrowserProfile
from e2b import Sandbox

BROWSER_PORT = 3000


async def main():
    browser_session = None
    sandbox = Sandbox.create(
        template=os.environ.get("E2B_BROWSER_TEMPLATE", "my-browser-template"),
        timeout=600,
        secure=True,
    )

    try:
        host = sandbox.get_host(BROWSER_PORT)
        cdp_url = f"wss://{host}/ws/automation"

        browser_session = BrowserSession(
            cdp_url=cdp_url,
            browser_profile=BrowserProfile(
                headless=False,
                keep_alive=True,
            ),
        )

        agent = Agent(
            task="访问 https://example.com，提取页面标题并总结首屏正文",
            llm=ChatOpenAI(
                model=os.environ.get("QWEN_MODEL", "qwen-vl-max"),
                api_key=os.environ["DASHSCOPE_API_KEY"],
                base_url="https://dashscope.aliyuncs.com/compatible-mode/v1",
            ),
            browser_session=browser_session,
            use_vision=True,
        )
        result = await agent.run()
        print(result)
    finally:
        if browser_session is not None:
            await browser_session.stop()
        sandbox.kill()


if __name__ == "__main__":
    asyncio.run(main())
```

这类接入方式适合搜索、比较、填写表单、点击确认和生成截图证据。需要稳定产物时，让 Agent 把关键结果写成 JSON，同时保留截图或 HTML 片段，便于人工复核和问题追踪。

## 上线建议

- 把每个浏览器任务限制在明确的 URL 范围内，必要时增加域名白名单。
- 限制下载文件类型、单文件大小、总输出大小和任务生命周期。
- 页面内容可能包含 prompt injection。不要让 Agent 未经校验地执行网页中的指令。
- 登录态、Cookie、账号凭证和业务 Token 应按任务隔离，通过运行时注入，不写入模板。
- 记录 URL、截图、关键 DOM 摘要、工具调用轨迹和结果文件路径。
- 如果需要人工观察或调试，镜像内置 noVNC 页面：`https://<sandbox-host>/static/vnc.html?path=/ws/livestream&autoconnect=true`。`path` 不能省略且必须以 `/` 开头（写成相对路径 `ws/livestream` 会解析到 `/static/ws/livestream` 并连接失败；镜像内没有 `defaults.json`），根路径 `/vnc.html` 为 404。默认平台域名（`*.e2b.fc.aliyuncs.com`）会附加 `Content-Disposition: attachment` 响应头，**触发下载而非打开页面**，需先[绑定自定义域名](../04.功能说明/07.FC%20扩展/03.自定义域名.md)；WebSocket 握手不加该响应头，外部 noVNC 客户端仍可直接连 `wss://<sandbox-host>/ws/livestream`（等价别名 `/ws/liveview`）。
- 如果任务需要在浏览器操作后继续运行 Python/Node.js 脚本处理数据，使用 [AIO Sandbox](03.使用%20AIO%20Sandbox.md)。
