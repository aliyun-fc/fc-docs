# 使用 Windows Computer Use Sandbox

> **访问说明**：`allow_public_traffic` 默认为 `True`，表示公网 URL **无需流量令牌**即可访问；设为 `False` 时所有公网请求必须携带 `e2b-traffic-access-token` 请求头，query 参数无效。`secure` 默认为 `True`，控制 SDK/envd 控制面鉴权，与流量令牌是两套独立令牌；示例省略默认的 `network` 参数，`secure=True` 为显式写出。公网 URL 应视为访问凭证：未设置应用层鉴权时，持有 URL 的人可完全控制沙箱桌面，请勿公开分享，也不要写入日志或前端代码。需要限制访问时，参见[网络访问控制](../04.功能说明/06.网络/05.网络访问控制.md)与[责任共担](../06.安全合规/01.责任共担.md)；受限 API Key 在 Enforce 模式下需具有 `sandbox.network.ingress`（Python SDK 只要传 `network` 就会附带发送 `allowPublicTraffic`，故必然置位；JS/TS SDK 与 REST 仅在显式设置 `allowPublicTraffic` 或 `maskRequestHost` 时才置位）与 `sandbox.network.egress`（SDK 默认发送 `allow_internet_access`）权限。受限模式下，服务端客户端可直接在 WebSocket 握手头携带 `e2b-traffic-access-token`；只有运行在浏览器页面内的客户端（如网页版 noVNC）无法自定义握手头，需由受控后端代理注入，或改用 `stream.start(require_auth=True)` + `stream.get_url(auth_key=...)`。

Windows Computer Use Sandbox 提供可由 Desktop SDK 操作的 Windows 桌面环境。本示例创建一个 Windows 沙箱，启动 noVNC 实时画面，在记事本中输入文本，并读取文件确认操作结果。

> **说明**：Windows Desktop 镜像只能由官方提供，暂不支持用户自行制作或导入 Windows 镜像。本文使用的官方镜像统一在下方 `.env` 中配置一次，后续示例不再重复声明镜像地址。

## 准备工作

1. 确认账号已开通 Windows Desktop 邀测权限，并确定要使用的地域，例如上海地域为 `cn-shanghai`。
2. 配置与模板同地域的 `E2B_API_KEY`、`E2B_API_URL` 和 `E2B_DOMAIN`。
3. 安装 Python 3.12、E2B SDK 和 Desktop SDK。

## 运行示例

将以下代码保存为 `windows_desktop_demo.py`：

```python
"""使用 Desktop SDK 操作 Windows，并通过 noVNC 查看实时画面。"""

from __future__ import annotations

import os
import time

from dotenv import load_dotenv
from e2b import CommandExitException
from e2b_desktop import Sandbox

DEMO_PATH = "/tmp/e2b-desktop-demo.txt"
DEMO_TEXT = "E2B Desktop SDK + Windows + noVNC\r\n中文输入与实时画面演示成功！"


def wait_for_notepad(desktop: Sandbox) -> str:
    """等待记事本窗口出现，并返回窗口 ID。"""
    for _ in range(40):
        try:
            windows = desktop.get_application_windows("Notepad")
            if windows and windows != [""]:
                return windows[0]
        except CommandExitException:
            pass
        time.sleep(0.25)
    raise RuntimeError("10 秒内未找到 Notepad 窗口")


def main() -> None:
    load_dotenv()
    template = os.environ["E2B_WINDOWS_DESKTOP_TEMPLATE"]

    desktop: Sandbox | None = None
    try:
        desktop = Sandbox.create(
            template=template,
            resolution=(1920, 1080),
            timeout=900,
            secure=True,
        )
        width, height = desktop.get_screen_size()
        print(f"Windows Desktop 已创建：{desktop.sandbox_id}，{width}x{height}")

        desktop.stream.start(require_auth=False)
        stream_url = desktop.stream.get_url()
        print(f"在浏览器中打开 noVNC 地址：\n{stream_url}")

        desktop.files.write(DEMO_PATH, "等待 SDK 输入……")
        desktop.commands.run(
            "Get-Process -Name notepad -ErrorAction SilentlyContinue "
            "| Stop-Process -Force; exit 0"
        )
        desktop.launch("notepad.exe", DEMO_PATH)

        window_id = wait_for_notepad(desktop)
        print(f"已启动窗口：{desktop.get_window_title(window_id)}")

        desktop.commands.run(f"xdotool windowactivate --sync {window_id}")
        desktop.press(["ctrl", "a"])
        desktop.write(DEMO_TEXT, chunk_size=64, delay_in_ms=20)
        desktop.press(["ctrl", "s"])
        desktop.wait(500)

        content = desktop.files.read(DEMO_PATH)
        if "中文输入与实时画面演示成功" not in content:
            raise RuntimeError("SDK 键盘输入未写入演示文件")
        print("键盘输入与文件校验成功。")

        input("按 Enter 结束示例并释放沙箱……")
    finally:
        if desktop is not None:
            desktop.kill()


if __name__ == "__main__":
    main()
```

> **说明**：示例用 `desktop.stream.start(require_auth=False)` 便于本地调试，noVNC 地址免口令即可打开（默认平台域名 `*.e2b.fc.aliyuncs.com` 会给该页面响应附加 `Content-Disposition: attachment`，浏览器表现为下载 `vnc.html` 而非打开页面，需先[绑定自定义域名](../04.功能说明/07.FC%20扩展/03.自定义域名.md)）；对外场景请改为 `desktop.stream.start(require_auth=True)`，再用 `desktop.stream.get_url(auth_key=desktop.stream.get_auth_key())` 生成带口令的地址（`get_auth_key()` 必须在 `require_auth=True` 之后调用，否则抛 `RuntimeError`）。

运行示例：

```bash
python windows_desktop_demo.py
```

程序输出 noVNC 地址后，在浏览器中打开该地址即可实时查看 Windows 桌面（默认平台域名会触发下载而非打开页面，需先[绑定自定义域名](../04.功能说明/07.FC%20扩展/03.自定义域名.md)）。示例会打开记事本、输入文本并读取文件校验结果；按 Enter 后，`finally` 块会销毁沙箱并释放资源。

## 使用 Snapshot 保存和恢复 Windows 沙箱

如果需要重复启动已经完成桌面初始化的 Windows 环境，可以先从运行中的 Windows 沙箱创建 Snapshot，再使用 Snapshot ID 创建新的沙箱。下面的完整示例依次执行以下操作：

1. 使用官方 Windows Desktop 镜像构建第二代运行时模板。
2. 使用模板 ID 创建源沙箱。
3. 等待 Windows 命令服务和 noVNC 首帧就绪，然后创建 Snapshot。
4. 使用 Snapshot ID 创建恢复沙箱，并验证 Windows 命令服务。
5. 输出恢复沙箱的 noVNC 地址。

> **使用限制**：Snapshot 当前处于邀测阶段，仅支持已开通白名单的账号和第二代运行时（`micro-sandbox`）。Windows Desktop 镜像由官方提供，暂不支持用户自行制作或导入。Snapshot 的默认保留时间、命名、删除和计费规则，请参见[快照（Snapshot）](../04.功能说明/01.沙箱/12.快照.md)。

# /// script
# requires-python = ">=3.10"
# dependencies = [
#     "e2b==2.45.1",
#     "httpx==0.28.1",
#     "python-dotenv==1.2.3",

# ///
"""E2B Windows Template/Sandbox/Snapshot 完整生命周期 demo（不绑定 region）。

region / endpoint / 镜像 / VPC 等全部由脚本同目录的 .env 指定，切换 region 只改
配置文件即可，无需改动脚本。

运行方式：
    uv run windows_snapshot_lifecycle.py

流程：
    1. 使用 Windows 镜像构建 Template
    2. 使用步骤 1 输出的 template_id 创建源 Sandbox
    3. 使用步骤 2 输出的 sandbox_id 创建 Snapshot
    4. 使用步骤 3 输出的 snapshot_id 恢复新 Sandbox
    5. 输出恢复 Sandbox 的 noVNC 链接

覆盖当前进程已有的同名环境变量。恢复 Sandbox 默认保留，方便立即访问 noVNC；

def require_env(name: str) -> str:
    value = os.getenv(name)
    if not value:
        raise RuntimeError(
            f"missing required env var: {name} (请在 {ENV_PATH} 中配置)")

def env_bool(name: str, default: bool = False) -> bool:
    value = os.getenv(name)
    return (

        if value is None

def get_api_params() -> ApiParams:

def build_windows_template(started_at: float) -> BuildInfo:
    rootfs_image = require_env("ROOTFS_IMAGE")
    cpu_count = int(os.getenv("E2B_TEMPLATE_CPU_COUNT", "16"))
    memory_mb = int(os.getenv("E2B_TEMPLATE_MEMORY_MB", "16448"))
    os_type = os.getenv("E2B_TEMPLATE_OS_TYPE", "windows")
    name_prefix = os.getenv("E2B_TEMPLATE_NAME_PREFIX",
                            "windows-snapshot-lifecycle")
    template_name = f"{name_prefix}-{os_type}-{time.time_ns()}"

    milestone(
        started_at, f"Step 1/5 building Windows Template from {rootfs_image}")
    template = Template().build_in_background(
        template=Template()
        .from_image(image=rootfs_image),
        name=template_name,
        cpu_count=cpu_count,
        memory_mb=memory_mb,
        skip_cache=env_bool("E2B_TEMPLATE_SKIP_CACHE", False),
        on_build_logs=default_build_logger(),
        **get_api_params(),
    )
    milestone(
        started_at,
        f"Template build accepted: template_id={template.template_id}, build_id={template.build_id}",
    )

    deadline = time.monotonic() + int(
        os.getenv("TEMPLATE_BUILD_TIMEOUT_SECONDS", "3600")
    )
    interval = int(os.getenv("TEMPLATE_BUILD_POLL_INTERVAL_SECONDS", "10"))
    while time.monotonic() < deadline:
        status = Template.get_build_status(
            template, logs_offset=0, **get_api_params())
        state = status.status.value
        if state == "ready":
            milestone(
                started_at, f"Step 1/5 complete: template_id={template.template_id}"
            )
            return template
        if state == "error":
            raise RuntimeError(f"template build failed: {status}")
        if state not in {"building", "waiting"}:
            raise RuntimeError(f"unexpected template build status: {status}")
        print(
            f"template_id={template.template_id} status={state}; waiting {interval}s..."
        )
        time.sleep(interval)

    raise TimeoutError(
        f"template build timed out: template_id={template.template_id}")

def find_recent_sandbox(source_id: str) -> Sandbox | None:
    """创建响应断开后，查找由同一 Template/Snapshot 创建的最近实例。"""
    try:
        paginator = Sandbox.list(limit=50, **get_api_params())
        candidates = []
        while paginator.has_next:
            for info in paginator.next_items():
                if info.template_id == source_id and str(info.state) not in {
                    "killed",
                    "dead",
                    "error",
                }:
                    candidates.append(info)
        if not candidates:
            return None
        latest = max(candidates, key=lambda info: info.started_at)
        return Sandbox.connect(
            latest.sandbox_id,
            timeout=int(os.getenv("SANDBOX_TIMEOUT_SECONDS", "900")),
            **get_api_params(),
        )
    except Exception as exc:
        print(f"sandbox recovery lookup failed: {type(exc).__name__}: {exc}")
        return None


def create_sandbox(source_id: str, started_at: float, step: int) -> Sandbox:
    """从 template_id 或 snapshot_id 创建 Sandbox，并处理 Windows 创建断连。"""
    timeout = int(os.getenv("SANDBOX_TIMEOUT_SECONDS", "900"))
    retry_waits = (30, 60, 90, 120)

    for attempt in range(1, len(retry_waits) + 2):
        try:
            sandbox = Sandbox.create(
                template=source_id,
                timeout=timeout,
                **get_api_params(),
            )
            milestone(
                started_at,
                f"Step {step}/5 complete: source_id={source_id}, sandbox_id={sandbox.sandbox_id}",
            )
            return sandbox
        except httpx.RemoteProtocolError as exc:
            if attempt > len(retry_waits):
                raise
            wait_seconds = retry_waits[attempt - 1]
            print(
                f"Sandbox.create response disconnected ({attempt}/5): {exc}; "
                f"waiting {wait_seconds}s before recovery"
            )
            time.sleep(wait_seconds)
            recovered = find_recent_sandbox(source_id)
            if recovered is not None:
                milestone(
                    started_at,
                    f"Step {step}/5 recovered: source_id={source_id}, "
                    f"sandbox_id={recovered.sandbox_id}",
                )
                return recovered

    raise RuntimeError(f"failed to create sandbox from source_id={source_id}")


def kill_sandbox(sandbox: Sandbox | None, label: str) -> None:
    if sandbox is None:
        return
    try:
        sandbox.kill()
        print(f"cleaned {label}: sandbox_id={sandbox.sandbox_id}")
    except Exception as exc:
        print(
            f"warning: failed to clean {label} sandbox_id={sandbox.sandbox_id}: "
            f"{type(exc).__name__}: {exc}"
        )


# =============================================================================
# Windows 数据面：等待服务并写入/验证快照标记
# =============================================================================


def execute_windows(sandbox: Sandbox, command: list[str]) -> dict:
    access_token = sandbox._envd_access_token
    if not access_token:
        raise RuntimeError(
            f"sandbox has no access token: sandbox_id={sandbox.sandbox_id}"
        )

    response = httpx.post(
        f"http://{sandbox.get_host(WINDOWS_SERVICE_PORT)}/execute",
        headers={"X-Access-Token": access_token},
        json={"command": command},
        timeout=30,
    )
    if response.is_error:
        raise RuntimeError(
            f"Windows /execute failed: status={response.status_code}, body={response.text}"
        )
    result = response.json()
    if result.get("returncode") != 0 or result.get("status") != "success":
        raise RuntimeError(
            f"Windows command failed: command={command}, result={result}"
        )
    return result


def wait_for_windows_service(
    sandbox: Sandbox, timeout: int = 180, interval: int = 5
) -> None:
    deadline = time.monotonic() + timeout
    last_error: Exception | None = None
    while time.monotonic() < deadline:
        try:
            execute_windows(sandbox, ["whoami"])
            return
        except Exception as exc:
            last_error = exc
            time.sleep(interval)
    raise TimeoutError(
        f"Windows service not ready: sandbox_id={sandbox.sandbox_id}, error={last_error}"
    )


# =============================================================================
# Step 3：使用源 sandbox_id 创建 Snapshot
# =============================================================================


def find_snapshot_id(snapshots: list, snapshot_name: str) -> str | None:
    expected_suffix = f"/{snapshot_name}:default"
    for snapshot in snapshots:
        if any(
            name == snapshot_name or name.endswith(expected_suffix)
            for name in snapshot.names
        ):
            return snapshot.snapshot_id
    return None


def lookup_snapshot_id(snapshot_name: str, sandbox_id: str) -> str | None:
    client = get_api_client(ConnectionConfig(**get_api_params()))
    response = get_snapshots.sync_detailed(
        client=client,
        sandbox_id=sandbox_id,
        name=snapshot_name,
        limit=100,
    )
    if response.status_code == 200 and isinstance(response.parsed, list):
        return find_snapshot_id(response.parsed, snapshot_name)
    return None


def discover_snapshot_after_disconnect(snapshot_name: str, sandbox_id: str) -> str:
    """create_snapshot 响应断开时查询服务端结果，避免重放非幂等请求。"""
    deadline = time.monotonic() + SNAPSHOT_DISCOVERY_TIMEOUT_SECONDS
    while time.monotonic() < deadline:
        snapshot_id = lookup_snapshot_id(snapshot_name, sandbox_id)
        if snapshot_id:
            return snapshot_id
        time.sleep(2)
    raise TimeoutError(
        f"snapshot not discoverable after disconnected response: "
        f"sandbox_id={sandbox_id}, name={snapshot_name}"
    )

        sandbox,
        started_at,
        timeout=int(os.getenv("NOVNC_READY_TIMEOUT_SECONDS", "600")),
    )
    snapshot_name = f"windows-snapshot-{time.time_ns()}"
    milestone(
        started_at,
        f"Step 3/5 creating Snapshot from sandbox_id={sandbox.sandbox_id}",
    )

    max_attempts = int(os.getenv("SNAPSHOT_CREATE_MAX_ATTEMPTS", "12"))
    retry_interval = int(
        os.getenv("SNAPSHOT_CREATE_RETRY_INTERVAL_SECONDS", "10"))
    snapshot_id = ""
    for attempt in range(1, max_attempts + 1):
        try:
            snapshot_info = sandbox.create_snapshot(
                name=snapshot_name, **get_api_params()
            )
            snapshot_id = snapshot_info.snapshot_id
            if not snapshot_id:
                raise RuntimeError(
                    f"snapshot creation returned no ID: {snapshot_info}")
            break
        except httpx.RemoteProtocolError as exc:
            print(f"snapshot response disconnected; discovering result: {exc}")
            snapshot_id = discover_snapshot_after_disconnect(
                snapshot_name, sandbox.sandbox_id
            )
            break
        except SandboxException as exc:
            if "503" not in str(exc) or attempt >= max_attempts:
                raise
            snapshot_id = lookup_snapshot_id(
                snapshot_name, sandbox.sandbox_id) or ""
            if snapshot_id:
                break
            print(
                f"snapshot is temporarily unavailable ({attempt}/{max_attempts}); "
                f"retrying in {retry_interval}s"
            )
            time.sleep(retry_interval)

    milestone(
        started_at,
        f"Step 3/5 complete: sandbox_id={sandbox.sandbox_id}, snapshot_id={snapshot_id}",
    )
    return snapshot_id

class WebSocketBinaryStream:
    """用于 noVNC/RFB 就绪探测的最小 WebSocket 二进制流。"""

    def __init__(self, sock: socket.socket, initial_data: bytes = b"") -> None:
        self.sock = sock
        self.raw_buffer = bytearray(initial_data)
        self.data_buffer = bytearray()

    def _recv_raw_exact(self, size: int) -> bytes:
        while len(self.raw_buffer) < size:
            chunk = self.sock.recv(65536)
            if not chunk:
                raise ConnectionError("WebSocket closed by peer")
            self.raw_buffer.extend(chunk)
        result = bytes(self.raw_buffer[:size])
        del self.raw_buffer[:size]
        return result

    def send_binary(self, payload: bytes, opcode: int = 0x2) -> None:
        mask = os.urandom(4)
        length = len(payload)
        header = bytearray([0x80 | opcode])
        if length < 126:
            header.append(0x80 | length)
        elif length <= 0xFFFF:
            header.append(0x80 | 126)
            header.extend(struct.pack("!H", length))
        else:
            header.append(0x80 | 127)
            header.extend(struct.pack("!Q", length))
        masked = bytes(value ^ mask[index % 4]
                       for index, value in enumerate(payload))
        self.sock.sendall(bytes(header) + mask + masked)

    def _recv_data_frame(self) -> bytes:
        while True:
            first, second = self._recv_raw_exact(2)
            opcode = first & 0x0F
            masked = bool(second & 0x80)
            length = second & 0x7F
            if length == 126:
                length = struct.unpack("!H", self._recv_raw_exact(2))[0]
            elif length == 127:
                length = struct.unpack("!Q", self._recv_raw_exact(8))[0]
            mask = self._recv_raw_exact(4) if masked else b""
            payload = self._recv_raw_exact(length)
            if masked:
                payload = bytes(
                    value ^ mask[index % 4] for index, value in enumerate(payload)
                )
            if opcode == 0x8:
                raise ConnectionError("WebSocket close frame received")
            if opcode == 0x9:
                self.send_binary(payload, opcode=0xA)
                continue
            if opcode in {0x0, 0x2}:
                return payload

    def read_exact(self, size: int) -> bytes:
        while len(self.data_buffer) < size:
            self.data_buffer.extend(self._recv_data_frame())
        result = bytes(self.data_buffer[:size])
        del self.data_buffer[:size]
        return result

    def discard_exact(self, size: int) -> None:
        remaining = size
        while remaining:
            if self.data_buffer:
                consumed = min(remaining, len(self.data_buffer))
                del self.data_buffer[:consumed]
                remaining -= consumed
                continue
            self.data_buffer.extend(self._recv_data_frame())


def connect_websocket(
    host: str, access_token: str, timeout: float
) -> WebSocketBinaryStream:
    sock = socket.create_connection((host, 80), timeout=timeout)
    sock.settimeout(timeout)
    key = base64.b64encode(os.urandom(16)).decode("ascii")
    request = (
        f"GET /websockify?accessToken={access_token} HTTP/1.1\r\n"
        f"Host: {host}\r\n"
        "Upgrade: websocket\r\n"
        "Connection: Upgrade\r\n"
        f"Origin: http://{host}\r\n"
        f"Sec-WebSocket-Key: {key}\r\n"
        "Sec-WebSocket-Version: 13\r\n"
        "Sec-WebSocket-Protocol: binary\r\n\r\n"
    )
    sock.sendall(request.encode("ascii"))
    response = bytearray()
    while b"\r\n\r\n" not in response:
        chunk = sock.recv(4096)
        if not chunk:
            raise ConnectionError("connection closed during WebSocket upgrade")
        response.extend(chunk)
    headers, initial_data = bytes(response).split(b"\r\n\r\n", 1)
    status_line = headers.split(b"\r\n", 1)[0]
    if b" 101 " not in status_line:
        sock.close()
        raise ConnectionError(
            f"WebSocket upgrade failed: {status_line.decode(errors='replace')}"
        )
    expected_accept = base64.b64encode(
        hashlib.sha1(
            (key + "258EAFA5-E914-47DA-95CA-C5AB0DC85B11").encode()).digest()
    )
    if expected_accept.lower() not in headers.lower():
        sock.close()
        raise ConnectionError("invalid Sec-WebSocket-Accept response")
    return WebSocketBinaryStream(sock, initial_data)


def probe_novnc_first_frame(
    sandbox: Sandbox, started_at: float, timeout: int = 600
) -> None:
    """完成 RFB 握手并读取首帧，确认 Windows 桌面已真正启动。"""
    host = f"{NOVNC_PORT}-{sandbox.sandbox_id}.{require_env('E2B_DOMAIN')}"
    access_token = sandbox._envd_access_token
    if not access_token:
        raise RuntimeError(
            f"sandbox has no access token: sandbox_id={sandbox.sandbox_id}"
        )

    deadline = time.monotonic() + timeout
    last_error: Exception | None = None
    while time.monotonic() < deadline:
        stream: WebSocketBinaryStream | None = None
        try:
            stream = connect_websocket(
                host, access_token, min(5, deadline - time.monotonic())
            )
            version = stream.read_exact(12)
            if not version.startswith(b"RFB "):
                raise RuntimeError(f"unexpected RFB version: {version!r}")
            stream.send_binary(version)

            security_type_count = stream.read_exact(1)[0]
            if security_type_count == 0:
                reason_length = struct.unpack("!I", stream.read_exact(4))[0]
                reason = stream.read_exact(
                    reason_length).decode(errors="replace")
                raise RuntimeError(f"RFB server rejected connection: {reason}")
            security_types = list(stream.read_exact(security_type_count))
            if 1 not in security_types:
                raise RuntimeError(
                    f"unsupported RFB security types: {security_types}")
            stream.send_binary(b"\x01")
            security_result = struct.unpack("!I", stream.read_exact(4))[0]
            if security_result != 0:
                raise RuntimeError(
                    f"RFB security negotiation failed: {security_result}"
                )

            stream.send_binary(b"\x01")
            width, height = struct.unpack("!HH", stream.read_exact(4))
            pixel_format = stream.read_exact(16)
            bytes_per_pixel = pixel_format[0] // 8
            name_length = struct.unpack("!I", stream.read_exact(4))[0]
            desktop_name = stream.read_exact(
                name_length).decode(errors="replace")

            stream.send_binary(struct.pack("!BBHi", 2, 0, 1, 0))
            stream.send_binary(struct.pack(
                "!BBHHHH", 3, 0, 0, 0, width, height))
            while True:
                message_type = stream.read_exact(1)[0]
                if message_type == 0:
                    header = stream.read_exact(3)
                    rectangle_count = struct.unpack("!H", header[1:])[0]
                    if rectangle_count:
                        for _ in range(rectangle_count):
                            rectangle = stream.read_exact(12)
                            _, _, rect_width, rect_height, encoding = struct.unpack(
                                "!HHHHi", rectangle
                            )
                            if encoding != 0:
                                raise RuntimeError(
                                    f"unexpected framebuffer encoding: {encoding}"
                                )
                            stream.discard_exact(
                                rect_width * rect_height * bytes_per_pixel
                            )
                        milestone(
                            started_at,
                            f"noVNC first frame ready: {width}x{height} {desktop_name!r}",
                        )
                        return
                elif message_type == 1:
                    header = stream.read_exact(5)
                    color_count = struct.unpack("!H", header[3:])[0]
                    stream.read_exact(color_count * 6)
                elif message_type == 2:
                    continue
                elif message_type == 3:
                    header = stream.read_exact(7)
                    text_length = struct.unpack("!I", header[3:])[0]
                    stream.read_exact(text_length)
                else:
                    raise RuntimeError(
                        f"unexpected RFB server message type: {message_type}"
                    )
        except (OSError, ConnectionError, TimeoutError) as exc:
            last_error = exc
            time.sleep(1)
        finally:
            if stream is not None:
                stream.sock.close()

    raise TimeoutError(
        f"noVNC first frame not ready: sandbox_id={sandbox.sandbox_id}, "
        f"error={last_error}"
    )


def get_novnc_url(sandbox: Sandbox) -> str:
    access_token = sandbox._envd_access_token
    if not access_token:
        raise RuntimeError(
            f"sandbox has no access token: sandbox_id={sandbox.sandbox_id}"
        )
    websocket_path = quote(f"websockify?accessToken={access_token}", safe="")
    scheme = os.getenv("SANDBOX_PUBLIC_SCHEME", "http")
    return (
        f"{scheme}://{NOVNC_PORT}-{sandbox.sandbox_id}.{require_env('E2B_DOMAIN')}"
        f"/vnc.html#autoconnect=true&resize=scale&path={websocket_path}"
    )


def wait_for_novnc(sandbox: Sandbox, timeout: int = 600, interval: int = 3) -> str:
    novnc_url = get_novnc_url(sandbox)
    deadline = time.monotonic() + timeout
    last_error: Exception | None = None
    while time.monotonic() < deadline:
        try:
            response = httpx.get(novnc_url, timeout=5)
            if response.status_code == 200 and "noVNC" in response.text:
                return novnc_url
            last_error = RuntimeError(f"HTTP {response.status_code}")
        except (httpx.HTTPError, OSError) as exc:
            last_error = exc
        time.sleep(interval)
    raise TimeoutError(
        f"noVNC not ready: sandbox_id={sandbox.sandbox_id}, error={last_error}"
    )


# =============================================================================
# 主流程：严格串联 5 个步骤，并按配置清理资源
# =============================================================================


def main() -> None:
    started_at = time.perf_counter()
    source_sandbox: Sandbox | None = None
    restored_sandbox: Sandbox | None = None
    workflow_succeeded = False

    template_id = ""
    snapshot_id = ""
    novnc_url = ""

    try:
        # Step 1: Windows image -> Template
        template = build_windows_template(started_at)
        template_id = template.template_id

        # Step 2: template_id -> source Sandbox
        source_sandbox = create_sandbox(template_id, started_at, step=2)

        # Step 3: source sandbox_id -> Snapshot
        snapshot_id = create_snapshot(source_sandbox, started_at)

        # Step 4: snapshot_id -> restored Sandbox
        restored_sandbox = create_sandbox(snapshot_id, started_at, step=4)
        wait_for_windows_service(restored_sandbox)
        identity = str(
            execute_windows(restored_sandbox, ["whoami"]).get("output", "")
        ).strip()
        milestone(
            started_at,
            f"Restored Sandbox is ready: snapshot_id={snapshot_id}, "
            f"restored_sandbox_id={restored_sandbox.sandbox_id}, whoami={identity!r}",
        )

        # Step 5: output restored Sandbox noVNC link
        probe_novnc_first_frame(
            restored_sandbox,
            started_at,
            timeout=int(os.getenv("NOVNC_READY_TIMEOUT_SECONDS", "600")),
        )
        novnc_url = wait_for_novnc(restored_sandbox)
        milestone(
            started_at,
            f"Step 5/5 complete: snapshot_id={snapshot_id}, noVNC is ready",
        )
        workflow_succeeded = True
    finally:
        if not env_bool("KEEP_SOURCE_SANDBOX", False):
            kill_sandbox(source_sandbox, "source")

        cleanup_restored = env_bool("CLEANUP_RESTORED_SANDBOX", False)
        if restored_sandbox is not None and (
            cleanup_restored or not workflow_succeeded
        ):
            kill_sandbox(restored_sandbox, "restored")

    if not workflow_succeeded or restored_sandbox is None:
        raise RuntimeError(
            "Windows Template/Sandbox/Snapshot lifecycle did not complete"
        )

    print("\nSUCCESS: Windows Template -> Sandbox -> Snapshot -> Restore -> noVNC\n")
    print(f"template_id={template_id}")
    print(f"snapshot_id={snapshot_id}")
    print(f"restored_sandbox_id={restored_sandbox.sandbox_id}")
    print(f"restored_sandbox_novnc_url={novnc_url}")
    if not env_bool("CLEANUP_RESTORED_SANDBOX", False):
        print(
            "restored sandbox is intentionally kept alive; "
            "set CLEANUP_RESTORED_SANDBOX=true to clean it automatically"
        )


if __name__ == "__main__":
    main()
