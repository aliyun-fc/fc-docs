# 使用 Windows Computer Use Sandbox

Windows Computer Use Sandbox 提供可由 Desktop SDK 操作的 Windows 桌面环境。本示例创建一个 Windows 沙箱，启动 noVNC 实时画面，在记事本中输入文本，并读取文件确认操作结果。

> **说明**：Windows Desktop 镜像只能由官方提供，暂不支持用户自行制作或导入 Windows 镜像。使用前，请先获取官方 Windows Desktop 镜像地址，再基于该镜像构建模板。

## 准备工作

1. 获取官方提供的 Windows Desktop 镜像地址，目前为邀请测试阶段，需要联系官方获取。
2. 配置与模板同地域的 `E2B_API_KEY`、`E2B_API_URL` 和 `E2B_DOMAIN`。
3. 安装 Python 3.12、E2B SDK 和 Desktop SDK。

创建虚拟环境并安装依赖：

```bash
python3.12 -m venv .venv
source .venv/bin/activate
pip install e2b e2b-desktop==2.4.2 python-dotenv
```

在项目目录中创建 `.env` 文件：

```dotenv
E2B_API_KEY=<your-api-key>
E2B_API_URL=<your-api-url>
E2B_DOMAIN=<your-domain>
E2B_WINDOWS_DESKTOP_IMAGE=<official-windows-desktop-image>
```

## 构建 Windows Desktop 模板

将以下代码保存为 `build_windows_template.py`：

```python
"""基于官方 Windows Desktop 镜像构建模板。"""

import os

from dotenv import load_dotenv
from e2b import Template, default_build_logger

load_dotenv()

image = os.environ["E2B_WINDOWS_DESKTOP_IMAGE"]
build = Template.build(
    Template().from_image(image),
    name="my-windows-desktop",
    cpu_count=8,
    memory_mb=8192,
    on_build_logs=default_build_logger(),
)
print(f"template_id: {build.template_id}")
```

运行模板构建：

```bash
python build_windows_template.py
```

构建完成后，将输出的模板 ID 写入 `.env`：

```dotenv
E2B_WINDOWS_DESKTOP_TEMPLATE=<windows-desktop-template-id>
```

## 运行示例

将以下代码保存为 `windows_desktop_demo.py`：

```python
"""使用 Desktop SDK 操作 Windows，并通过 noVNC 查看实时画面。"""

from __future__ import annotations

import os
import time

from dotenv import load_dotenv
from e2b import CommandExitException
from e2b_desktop import Sandbox

DEMO_PATH = "/tmp/e2b-desktop-demo.txt"
DEMO_TEXT = "E2B Desktop SDK + Windows + noVNC\r\n中文输入与实时画面演示成功！"


def wait_for_notepad(desktop: Sandbox) -> str:
    """等待记事本窗口出现，并返回窗口 ID。"""
    for _ in range(40):
        try:
            windows = desktop.get_application_windows("Notepad")
            if windows and windows != [""]:
                return windows[0]
        except CommandExitException:
            pass
        time.sleep(0.25)
    raise RuntimeError("10 秒内未找到 Notepad 窗口")


def main() -> None:
    load_dotenv()
    template = os.environ["E2B_WINDOWS_DESKTOP_TEMPLATE"]

    desktop: Sandbox | None = None
    try:
        desktop = Sandbox.create(
            template=template,
            resolution=(1920, 1080),
            timeout=900,
        )
        width, height = desktop.get_screen_size()
        print(f"Windows Desktop 已创建：{desktop.sandbox_id}，{width}x{height}")

        desktop.stream.start(require_auth=False)
        stream_url = desktop.stream.get_url()
        print(f"在浏览器中打开 noVNC 地址：\n{stream_url}")

        desktop.files.write(DEMO_PATH, "等待 SDK 输入……")
        desktop.commands.run(
            "Get-Process -Name notepad -ErrorAction SilentlyContinue "
            "| Stop-Process -Force; exit 0"
        )
        desktop.launch("notepad.exe", DEMO_PATH)

        window_id = wait_for_notepad(desktop)
        print(f"已启动窗口：{desktop.get_window_title(window_id)}")

        desktop.commands.run(f"xdotool windowactivate --sync {window_id}")
        desktop.press(["ctrl", "a"])
        desktop.write(DEMO_TEXT, chunk_size=64, delay_in_ms=20)
        desktop.press(["ctrl", "s"])
        desktop.wait(500)

        content = desktop.files.read(DEMO_PATH)
        if "中文输入与实时画面演示成功" not in content:
            raise RuntimeError("SDK 键盘输入未写入演示文件")
        print("键盘输入与文件校验成功。")

        input("按 Enter 结束示例并释放沙箱……")
    finally:
        if desktop is not None:
            desktop.kill()


if __name__ == "__main__":
    main()
```

运行示例：

```bash
python windows_desktop_demo.py
```

程序输出 noVNC 地址后，在浏览器中打开该地址即可实时查看 Windows 桌面。示例会打开记事本、输入文本并读取文件校验结果；按 Enter 后，`finally` 块会销毁沙箱并释放资源。
