# Team 与订阅计划

Team 用于在云沙箱中划分工作区，并承载订阅计划与资源组归属。同一账号下可以创建多个 Team，分别用于不同业务、环境或权限范围。API Key、Template 和 Sandbox 都属于某个 Team；创建 API Key 时需要选择 Team，该 Key 后续创建的 Sandbox 也归属对应 Team。

订阅计划（Plan）属于 Team，决定该 Team 下沙箱的可用能力。需要限制 Team 可用的 CPU 和内存总量时，参见[Team 配额管理](https://help.aliyun.com/zh/functioncompute/quota-management)。创建和使用 API Key 的步骤参见[创建 API Key](https://help.aliyun.com/zh/functioncompute/create-api-key)。

## 前提条件

创建和管理 Team 前，请确认：

- 已开通函数计算服务。
- 已开通云沙箱功能。
- 当前账号或 RAM 用户具备管理云沙箱 Team 的权限。
- 如需按业务拆分资源组，已在[资源管理控制台](https://resourcemanager.console.aliyun.com)创建资源组，并为 RAM 用户完成授权。

## Team、资源组、订阅计划与 API Key

| 对象 | 说明 |
|------|------|
| Team | 云沙箱工作区。订阅计划、资源组归属和配额都以 Team 为管理单元。 |
| 资源组 | 阿里云资源分组与 RAM 授权边界。创建 Team 时指定所属资源组；同一资源组下可以有多个 Team。 |
| 订阅计划 | Team 的能力档位。各计划能力差异参见[云沙箱多版本订阅计划功能差异](https://help.aliyun.com/zh/functioncompute/feature-differences-in-the-multi-version-subscription-plan-for-cloud-sandboxes)。 |
| API Key | 数据面访问凭证。每个 API Key 绑定一个 Team，并继承该 Team 的订阅计划和资源组上下文。 |

关系如下：

```text
资源组
└── Team
    ├── 订阅计划
    ├── API Key
    ├── Template
    └── Sandbox
```

- 创建 API Key 时必须指定 Team；创建后不能改绑到其他 Team。
- 同一 Team 下的 Template 和 Sandbox 跟随该 Team 的订阅计划。
- 控制台按资源组和 Team 筛选实例、模板和 API Key 列表。

## 创建 Team

1. 登录函数计算控制台，进入任一云沙箱页面，例如[云沙箱 API Keys](https://fcnext.console.aliyun.com/cn-beijing/sandbox-api-keys)、[云沙箱实例](https://fcnext.console.aliyun.com/cn-beijing/sandbox-instances)、[云沙箱模板](https://fcnext.console.aliyun.com/cn-beijing/sandbox-templates)或[云沙箱域名](https://fcnext.console.aliyun.com/cn-beijing/sandbox-domains)。
2. 确认页面左上角的资源组。资源组会影响 Team 列表范围，创建 Team 时也会默认带上当前资源组。
3. 在左侧导航顶部的 Team 选择器中，单击**创建 Team**。也可以在**管理 Team**抽屉，或创建 API Key 表单中单击**创建 Team**。
4. 在创建对话框中填写配置项，单击**确认创建**。

| 配置项 | 是否必填 | 说明 |
|--------|----------|------|
| Team 名称 | 是 | 创建后不可修改。只能包含字母和数字，并使用空格、下划线 `_`、连字符 `-` 或点号 `.` 分隔。建议使用可追溯命名，例如 `agent-prod`、`eval-test`。 |
| 资源组 | 是 | Team 所属的阿里云资源组。默认预填当前控制台选中的资源组；未选中时通常预填账号默认资源组。 |
| 订阅计划 | 是 | Team 及下属资源沿用该订阅计划。默认 Pro；创建后暂不支持降级。未开放多版本选择的地域不展示该字段，系统按 Pro 创建。 |
| 描述 | 否 | 最多 100 个字符，用于说明 Team 用途。 |

创建成功后，可在 Team 选择器和管理抽屉中查看 Team 名称与 Team ID。后续创建 API Key、查看实例和模板前，请确认当前筛选的 Team 正确。

## 订阅计划

订阅计划决定 Team 下沙箱可用的运行能力。控制台创建 Team 时默认选择 Pro；创建后只支持向更高档位升级，不支持在控制台降级。如需使用更低档位，请新建 Team，或联系产品支持。

各订阅计划的能力差异、典型场景和计费说明，参见[云沙箱多版本订阅计划功能差异](https://help.aliyun.com/zh/functioncompute/feature-differences-in-the-multi-version-subscription-plan-for-cloud-sandboxes)。计费细则参见[按量付费](https://help.aliyun.com/zh/functioncompute/pay-as-you-go-of-fc-agent-sandbox)。

如果请求超出当前订阅计划允许的能力范围，例如超时时间超限或不支持的休眠操作，请求会失败。此时应调整请求参数，或升级 Team 的订阅计划。

## 管理 Team

1. 打开任一云沙箱页面。
2. 在 Team 选择器中单击**管理 Team**。
3. 在管理抽屉中查看 Team ID、名称、版本（订阅计划）、描述、资源组、所有者和创建时间，并按 Team 名称或所有者 UID 搜索。

可执行的操作：

| 操作 | 说明 |
|------|------|
| 创建 Team | 与上文创建流程相同。 |
| 升级 | 将订阅计划升级到更高档位，升级路径为 Eco → Std → Pro。不支持降级。 |
| 删除 | 删除前会展示关联的 API Key、Sandbox 和 Template 数量。Team 下仍存在 API Key 时不能删除，需先到 API Key 页面清理后再删。 |

当前控制台不支持修改 Team 名称和描述，也不支持变更 Team 所属资源组。请在创建时确认名称和资源组。

## 创建 API Key 时选择 Team

1. 进入[云沙箱 API Keys 管理页面](https://fcnext.console.aliyun.com/cn-beijing/sandbox-api-keys)。
2. 单击**创建 API Key**。
3. 在表单中选择 **Team**。可选列表按当前资源组过滤；若当前资源组下没有 Team，可在表单中直接创建。
4. 填写描述和过期时间后完成创建。

API Key 会绑定所选 Team。使用该 Key 通过 SDK 或 CLI 创建的 Sandbox，归属对应 Team，并受该 Team 订阅计划约束。完整创建步骤和安全建议参见[创建 API Key](https://help.aliyun.com/zh/functioncompute/create-api-key)。

## 使用建议

- 按业务、环境或项目拆分 Team，例如生产、测试、评测各自使用独立 Team。
- 需要按 RAM 权限隔离时，先规划资源组，再在对应资源组下创建 Team。
- 按 Team 拆分 API Key，不要让多个环境和业务共用一个长期 Key。
- 需要限制 Team 可用 CPU / 内存总量时，记录 Team ID，并按[Team 配额管理](https://help.aliyun.com/zh/functioncompute/quota-management)配置配额。

## 常见问题

### 创建 API Key 前必须先有 Team 吗？

是。创建 API Key 时需要选择 Team。若目标资源组下还没有 Team，请先创建，或在创建 API Key 表单中直接创建 Team。

### 如何获取 Team ID？

在 Team 选择器中打开**管理 Team**，列表中的 Team ID 列可直接复制。配置 Team 配额时，将该值填入 `TagValue`。

### 为什么创建 Team 时看不到订阅计划？

多版本订阅计划按地域开放。未开放的地域创建 Team 时不展示计划选择器，系统按 Pro 创建。

### 可以把已有 Team 改到另一个资源组吗？

当前控制台不支持变更 Team 所属资源组。请在创建时选择正确的资源组。如需调整归属，请在目标资源组下新建 Team，并切换对应 API Key 与业务流量。

### 删除 Team 时提示存在 API Key 怎么办？

Team 下仍有 API Key 时不能删除。先到 API Key 页面删除相关 Key，再删除 Team。删除前请确认该 Team 下不再有需要保留的业务资源。

### 云沙箱 Team 是否通过 E2B SDK 管理？

否。云沙箱 Team 在函数计算控制台创建和管理，不通过 E2B SDK 的 Team API 管理。日常接入仍使用 E2B SDK 创建和操作 Sandbox，身份来自云沙箱 API Key 及其绑定的 Team。
