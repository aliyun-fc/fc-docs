# 云沙箱多版本功能差异
## 云沙箱多版本目标客户和场景
| Plan | 目标客户 | 典型场景 | 算力特征 |
|------|---------|---------|---------|
| Eco | AI初创团队、<br>个人开发者 | **Agent 尝鲜与功能测试**：<br>单步调试、工具调用（Tool Use）链路验证、低频异步长任务。 | **极低门槛**：<br>允许偶有算力扰动，性价比首选。 |
| Stad（推荐） | 中腰部企业，<br>AI SaaS厂商 | **企业内部 Copilot / 效能工具**：<br>日常办公助理、数据分析（Code Interpreter）、文档解析与格式转换。<br>**大规模离线采样与并行训练**：<br>性价比首选，能容忍秒级冷启动，提供海量低成本沙箱。 | **通用均衡**：<br>性能相对稳定，低延时响应，企业级生产可用。 |
| Pro（推荐） | 头部 AI 应用企业、MaaS/Agent 平台 | **C端高并发 Agent 应用**：<br>多智能体协同、海量用户并发的代码执行与重度复杂计算。<br>**大规模在线RL仿真**：<br>瞬时拉起海量沙箱环境，支持极低延迟、高并发、高吞吐的RL 环境采样与仿真。 | **弹性高吞吐**：<br>支持百万级沙箱并发，极低延迟。<br>完美支撑高并发 Agent 代码执行与 RL 大规模分布式高吞吐采样。 |
