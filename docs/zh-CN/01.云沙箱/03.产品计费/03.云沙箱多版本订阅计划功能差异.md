# 云沙箱多版本订阅计划
## 多版本订阅计划典型场景和算力特征
| Plan | 算力特征  | 典型场景 |
|------|---------|---------|
| Eco | **高性价比** <br> 允许算力扰动，性价比首选。 | Agent 开发调试、Tool Use 链路验证、低频 Code Interpreter。|
| Std（推荐） | **通用均衡、弹性高吞吐** <br> 性能相对稳定，超大规模交付，低延时响应，企业级生产可用。| Code Interpreter 生产服务、C 端高并发 Agent 执行、大规模采样与 RL 仿真、多租户沙箱隔离。|
| Pro（推荐） | **资源刚性交付** <br> 专属资源池供给保证算力稳定，支持浅休眠1ms 极速唤醒。|专属资源池刚性交付、算力零波动；生产级 RL 训练、金融量化/实时决策、多智能体长链路编排。|

* 注：<br>
1.**高并发深休眠唤醒效率**：指在2C4G规格，万级并发场景下，完成深休眠实例恢复以及网络重建的总耗时。<br>
2.**深休眠**：对标E2B Pause/Resume功能，沙箱未暂停时最大存活时长：Eco/Std/Pro都是24小时。暂停后计时器自动清零，恢复后重新获得完整时长。通过“暂停-恢复-暂停-恢复”循环，通可以实现持续延长沙箱在线周期。<br>
3.**浅休眠**：Pro版独有。基于请求感知与内存快照技术，当实例空闲（CPU消耗 < 0.01core 或 网络流量< 1,000 Bytes/s 或 无请求）时自动进入浅休眠以降低成本。浅休眠状态下 vCPU 不产生费用，内存和磁盘仍计费；有请求时 1ms 极速唤醒。<br>
4.**最大存活时长**：Eco/Std/Pro 默认为 24小时。如需延长请提交工单，平台针对存量 Pro 超时限实例自动兼容。<br>
5.**深休眠保留时长**：Eco/Std/Pro 默认为 7天。如需延长请提交工单，平台针对存量 Pro 超时限实例自动兼容。

## 订阅计划管理
**购买与计费**：免开通，按量付费（邀测阶段以控制台和开通约定为准）。创建/管理Team时设置订阅计划，可选设置Eco/Std/Pro版本。<br>
**生效机制**：订阅计划属性由 Team 层级向下继承。当前Team 下的所有 Template 和 Sandbox 均自动同步该计划属性，保持全局一致。<br>
**变更和管理**：<br>
* 升降级：支持单向平滑升级（Eco → Std → Pro）和降级操作（Pro → Std → Eco），可在 Team 设置中直接操作。<br> 降级后，除了算力QoS会下降外，从Pro → Std后也会导致浅休眠功能不生效。
