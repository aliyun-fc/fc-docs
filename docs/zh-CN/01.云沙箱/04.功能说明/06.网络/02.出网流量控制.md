# 出网流量控制

出网访问控制用于限制沙箱主动访问的网络目标。通过 `allowInternetAccess`、`allowOut` 和 `denyOut`，可以禁止全部出网，或只允许访问指定 IP、CIDR 和域名。

## 适用场景

- 运行不可信代码或第三方任务时，禁止访问外部网络。
- Agent 只需调用指定 API 时，将出网范围收敛到目标服务。
- 阻止沙箱访问特定 IP、网段或域名。

## 配置沙箱

| 参数 | 作用 |
| --- | --- |
| `allowInternetAccess` / `allow_internet_access` | 出网总开关，默认为 `true` |
| `network.allowOut` / `allow_out` | 允许访问的 IP、CIDR 或域名 |
| `network.denyOut` / `deny_out` | 拒绝访问的 IP、CIDR 或域名 |

### 禁止全部出网

> `allowInternetAccess: false` 会同时拒绝公网和 VPC 出站流量。若只需关闭公网出口并保留 VPC 访问，请在构建 E2B 模板时，将 `runtime_config.internet_access` 设为 `false`，并完整配置 `runtime_config.vpc_config`。具体配置见[构建和管理模板](../02.模板/03.通过%20OpenAPI%20构建和管理模板.md#运行时网络)。

**Node.js**

```typescript
import { Sandbox } from "e2b";

const sandbox = await Sandbox.create("code-interpreter-v1", {
  allowInternetAccess: false,
});
```

**Python**

```python
from e2b import Sandbox

sandbox = Sandbox.create(
    template="code-interpreter-v1",
    allow_internet_access=False,
)
```

`allowInternetAccess: false` 等价于拒绝 `0.0.0.0/0`。如果同时配置 `allowOut`，命中允许清单的目标仍可访问。

### 仅允许指定目标

以下配置仅允许访问 `api.example.com` 和 `example.com`：

**Node.js**

```typescript
import { Sandbox } from "e2b";

const sandbox = await Sandbox.create("code-interpreter-v1", {
  network: {
    allowOut: ["api.example.com", "example.com"],
    denyOut: ["0.0.0.0/0"],
  },
});
```

**Python**

```python
from e2b import Sandbox

sandbox = Sandbox.create(
    template="code-interpreter-v1",
    network={
        "allow_out": ["api.example.com", "example.com"],
        "deny_out": ["0.0.0.0/0"],
    },
)
```

`allowOut` 和 `denyOut` 均支持 IP、CIDR、精确域名和通配子域名。例如，`denyOut: ["example.com", "*.example.com"]` 会拒绝访问该域名及其子域名。

## 验证出网控制

在沙箱内使用 `curl` 验证允许目标：

```bash
curl -i --max-time 5 https://example.com
```

验证未允许的目标：

```bash
curl -i --max-time 5 https://example.org
```

命中允许清单的请求会返回目标服务的响应；被拒绝的请求无法获得有效的 HTTP 响应。

## 匹配规则

1. `allowOut` 优先于 `denyOut`。同一目标同时命中时放行。
2. 仅配置 `allowOut` 不会自动拒绝其他目标。白名单模式需要同时拒绝 `0.0.0.0/0`，或设置 `allowInternetAccess: false`。
3. 域名过滤仅覆盖 HTTP 80 和 TLS 443 端口，其他端口只能按 IP 或 CIDR 过滤。
4. 配置域名规则后，系统会自动放行默认 DNS 服务以完成解析。

常见组合的效果：

| 配置 | 效果 |
| --- | --- |
| 不配置任何出网参数 | 允许访问全部公网 |
| `allowInternetAccess: false` | 禁止全部出网 |
| `allowInternetAccess: false` + `allowOut` | 默认拒绝，仅允许命中 `allowOut` 的目标 |
| 仅配置 `denyOut` | 拒绝命中的目标，其余目标放行 |
| `denyOut: ["0.0.0.0/0"]` + `allowOut` | 仅允许命中 `allowOut` 的目标 |

## 更新配置

沙箱运行期间可通过 `updateNetwork` 修改出网规则，具体操作见[更新网络配置](./04.更新网络配置.md)。

## 使用限制

- `network.egressProxy` 当前不支持。
- 域名过滤仅支持 HTTP 80 和 TLS 443 端口，不支持通过域名控制其他端口或 UDP 流量。
- 被拒绝的 TCP 连接可能在沙箱内表现为已经建立，应以 HTTP 响应、TLS 握手或业务协议响应判断是否真正连通。
- `network.rules` 用于请求 Header 转换和凭证注入，具体用法见[凭证注入概述](./03.凭证注入/01.凭证注入总览.md)。
