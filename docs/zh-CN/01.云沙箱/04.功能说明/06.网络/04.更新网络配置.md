# 更新网络配置

沙箱运行期间，可以使用 `updateNetwork`（Node.js）或 `update_network`（Python）同时更新出网规则和凭证注入规则，无需重建沙箱。

## 更新配置

`updateNetwork` 使用全量替换语义，不会与现有配置合并。每次调用都必须提交最终需要保留的 `allowInternetAccess`、`allowOut`、`denyOut` 和 `rules`：

- 更新凭证注入规则时，需要同时提交要保留的出网规则。
- 更新出网规则时，需要同时提交要保留的凭证注入规则。
- 未提交的现有配置不会自动保留；省略 `rules`、传入 `null` 或 `{}` 会清空已有凭证注入规则。

以下示例同时更新出网白名单和 API Key 注入规则：

**Node.js**

```typescript
await sandbox.updateNetwork({
  allowInternetAccess: true,
  allowOut: ["api.example.com"],
  denyOut: ["0.0.0.0/0"],
  rules: {
    "api.example.com": [{
      transform: {
        headers: {
          Authorization: "Bearer ${fc.sandbox.identity.apiKey:new-model-provider}",
        },
      },
    }],
  },
});
```

**Python**

```python
sandbox.update_network({
    "allow_internet_access": True,
    "allow_out": ["api.example.com"],
    "deny_out": ["0.0.0.0/0"],
    "rules": {
        "api.example.com": [{
            "transform": {
                "headers": {
                    "Authorization":
                        "Bearer ${fc.sandbox.identity.apiKey:new-model-provider}"
                }
            }
        }]
    },
})
```

出网规则的配置方法见[出网流量控制](./02.出网流量控制.md)，凭证规则的配置方法见[凭证注入概述](./03.凭证注入/01.凭证注入总览.md)。

## 查询当前配置

`getInfo` 或 `GET /sandboxes/{id}` 会返回当前网络配置，可用于构造下一次完整的更新请求。

自带凭证方式会明文返回 replacement 的真实 `value`，不要把查询响应写入普通日志、工单或前端上报。Agent Identity 托管方式只返回引用表达式，不返回真实凭证。

## 生效规则

- 只有运行中的沙箱支持更新；暂停的沙箱需要先恢复。
- 更新失败时，原配置继续生效。
- 网络配置会跨 Pause 和 Resume 保留，并在恢复后的实例上重新应用。

## 不支持更新的配置

- `allowPublicTraffic` 和 `maskRequestHost` 只能在创建沙箱时设置。
- Workload Identity、Role Policy 和重签域名通过 `metadata` 配置，不能通过 `updateNetwork` 修改；需要更换时，请创建新沙箱。
- M2M OAuth 和用户委托 OAuth 的身份字段具有各自的更新规则，分别见[M2M OAuth 注入](./03.凭证注入/05.M2M%20OAuth%20注入.md#更新配置)和[用户委托 OAuth 注入](./03.凭证注入/06.用户委托%20OAuth%20注入.md#更新配置与切换用户)。
