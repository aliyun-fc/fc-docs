# 访问沙箱 HTTP 端口

在沙箱内启动 HTTP 服务后，通过 `getHost(port)` 获取公网访问地址。

## 适用场景

- 预览沙箱内运行的 Web 应用或开发服务器。
- 从沙箱外调用临时 HTTP API。
- 访问 Notebook、管理面板等基于浏览器的工具。

仅在需要从沙箱外访问内部 HTTP 服务时使用此功能。运行普通命令或从沙箱主动访问外部服务时，无需调用 `getHost(port)`。

## 启动服务并访问

**Node.js**

```typescript
import { Sandbox } from "e2b";

const sandbox = await Sandbox.create("code-interpreter-v1");

try {
  const handle = await sandbox.commands.run("python3 -m http.server 8000", {
    background: true,
  });

  const host = sandbox.getHost(8000);
  const url = `https://${host}`;
  console.log(url);

  const response = await fetch(url);
  console.log(await response.text());

  await sandbox.commands.kill(handle.pid);
} finally {
  await sandbox.kill();
}
```

**Python**

```python
import urllib.request
import time

from e2b import Sandbox

sandbox = Sandbox.create(template="code-interpreter-v1")

try:
    handle = sandbox.commands.run(
        "python3 -m http.server 8000",
        background=True,
    )
    time.sleep(2)

    host = sandbox.get_host(8000)
    url = f"https://{host}"
    print(url)

    with urllib.request.urlopen(url, timeout=10) as response:
        print(response.read().decode())

    handle.kill()
finally:
    sandbox.kill()
```

## 配置公网访问鉴权

通过 `getHost(port)` 暴露的沙箱服务默认可直接访问。`secure` 和 `allowPublicTraffic` 控制不同的访问入口：

| 参数 | 控制对象 | 默认值 | 作用 |
| --- | --- | --- | --- |
| `secure` | SDK 对沙箱的操作，例如执行命令、读写文件 | `true` | 为沙箱控制接口启用 `envdAccessToken` 鉴权，SDK 会自动携带令牌 |
| `allowPublicTraffic` | 外部访问 `getHost(port)` 暴露的服务 | `true` | `true` 表示公开访问；`false` 表示必须携带 `trafficAccessToken` |

若要开启公网访问鉴权，创建沙箱时设置 `allowPublicTraffic: false`。

**Node.js**

```typescript
import { Sandbox } from "e2b";

const sandbox = await Sandbox.create("code-interpreter-v1", {
  network: {
    allowPublicTraffic: false,
  },
});
```

**Python**

```python
from e2b import Sandbox

sandbox = Sandbox.create(
    template="code-interpreter-v1",
    network={"allow_public_traffic": False},
)
```

### 验证公网访问鉴权

不携带流量令牌访问：

```bash
curl -i "https://<sandbox-host>"
```

响应状态码为 `403`。

携带创建沙箱时返回的 `trafficAccessToken` 访问：

```bash
curl -i "https://<sandbox-host>" \
  -H "e2b-traffic-access-token: <traffic-access-token>"
```

请求通过鉴权后，返回沙箱内服务的响应。

### 获取流量令牌

创建、连接或恢复沙箱时会返回 `trafficAccessToken`。`getInfo` 和 `list` 不返回该令牌；丢失后可通过 `connect` 重新获取。

`trafficAccessToken` 与 `envdAccessToken` 用途不同：

| 令牌 | 用途 | 请求头 |
| --- | --- | --- |
| `trafficAccessToken` | 访问沙箱内服务的公网地址 | `e2b-traffic-access-token` |
| `envdAccessToken` | SDK 访问沙箱控制面 | `X-Access-Token` |

### 使用限制

- `allowPublicTraffic` 只能在创建沙箱时设置，不能通过 `updateNetwork` 修改。
- 流量令牌必须通过 `e2b-traffic-access-token` 请求头传递，不支持 query 参数。
- `secure` 控制 SDK 与沙箱控制面的鉴权，不能替代公网访问鉴权。

## 修改 Host 请求头

部分 Web 服务只接受 `localhost` 等特定 Host。创建沙箱时设置 `maskRequestHost`，可以修改转发到沙箱服务的 `Host` 请求头。

**Node.js**

```typescript
const sandbox = await Sandbox.create("code-interpreter-v1", {
  network: {
    maskRequestHost: "localhost:${PORT}",
  },
});
```

**Python**

```python
sandbox = Sandbox.create(
    template="code-interpreter-v1",
    network={"mask_request_host": "localhost:${PORT}"},
)
```

`${PORT}` 会自动替换为实际访问的端口。例如，通过 `getHost(8000)` 访问服务时，沙箱内收到的 `Host` 请求头为 `localhost:8000`。

`maskRequestHost` 只能在创建沙箱时设置，不能通过 `updateNetwork` 修改。

## 注意事项

- 调用 `getHost(port)` 前，需要确保沙箱内已有服务监听对应端口。
- `getHost(port)` 返回 host，访问时拼接 `https://`。
- 后台服务不会自动退出，任务完成后主动终止进程或终止沙箱。
- 不要在未鉴权的端口服务中暴露敏感数据或内部调试接口。
- 访问地址适合临时服务预览，不建议作为长期生产域名；自定义域名参见 [FC 扩展](../../07.FC%20扩展/03.自定义域名.md)。
