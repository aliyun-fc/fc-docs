# 自带阿里云 STS 注入

您可以自行提供 STS 或普通 AK/SK，在沙箱内使用占位 AK 调用业务 SDK，无需将真实凭证放入沙箱。支持多账号，无需配置 Workload Identity 或 RAM Role。

凭证由您获取并轮转；需要平台自动获取和刷新 STS 时，使用[托管阿里云 STS 注入](./03.托管阿里云%20STS%20注入.md)。

## 配置沙箱

在 `network.rules` 的固定配置键 `fc.sandbox.network.resign-credentials` 下配置凭证映射。每条映射的 `placeholder` 为占位 AK，`value` 为包含以下字段的 JSON 字符串：

| 字段 | 是否必填 | 说明 |
| --- | --- | --- |
| `accessKeyId` | 是 | 真实 AccessKey ID |
| `accessKeySecret` | 是 | 真实 AccessKey Secret |
| `securityToken` | 否 | 使用 STS 时填写；普通 AK/SK 省略 |

以下代码在**沙箱外**运行，从环境变量读取账号 A、B 的凭证。示例通过 `*.aliyuncs.com` 放行阿里云服务域名，可按需调整 `allowOut`；固定配置键无需加入其中。

**Node.js**

```typescript
import { Sandbox } from "e2b";

function readCredential(prefix: string) {
  const accessKeyId = process.env[`${prefix}_ACCESS_KEY_ID`];
  const accessKeySecret = process.env[`${prefix}_ACCESS_KEY_SECRET`];
  if (!accessKeyId || !accessKeySecret) {
    throw new Error(`${prefix}: AccessKey ID and Secret are required`);
  }
  return JSON.stringify({
    accessKeyId,
    accessKeySecret,
    securityToken: process.env[`${prefix}_SECURITY_TOKEN`],
  });
}

const entries = [
  { placeholder: "sandbox-ak-account-a", value: readCredential("ACCOUNT_A") },
  { placeholder: "sandbox-ak-account-b", value: readCredential("ACCOUNT_B") },
];

const network = {
  allowInternetAccess: true,
  allowOut: ["*.aliyuncs.com"],
  denyOut: ["0.0.0.0/0"],
  rules: {
    "fc.sandbox.network.resign-credentials": [{
      transform: {
        headers: {
          "fc.sandbox.network.header-value-replacements": JSON.stringify(entries),
        },
      },
    }],
  },
};

const sandbox = await Sandbox.create({ network });
```

**Python**

```python
import json
import os
from e2b import Sandbox


def read_credential(prefix):
    credential = {
        "accessKeyId": os.environ[f"{prefix}_ACCESS_KEY_ID"],
        "accessKeySecret": os.environ[f"{prefix}_ACCESS_KEY_SECRET"],
    }
    token = os.environ.get(f"{prefix}_SECURITY_TOKEN")
    if token:
        credential["securityToken"] = token
    return json.dumps(credential, separators=(",", ":"))


entries = [
    {"placeholder": "sandbox-ak-account-a", "value": read_credential("ACCOUNT_A")},
    {"placeholder": "sandbox-ak-account-b", "value": read_credential("ACCOUNT_B")},
]

network = {
    "allow_internet_access": True,
    "allow_out": ["*.aliyuncs.com"],
    "deny_out": ["0.0.0.0/0"],
    "rules": {
        "fc.sandbox.network.resign-credentials": [{
            "transform": {
                "headers": {
                    "fc.sandbox.network.header-value-replacements":
                        json.dumps(entries, separators=(",", ":"))
                }
            }
        }]
    },
}

sandbox = Sandbox.create(network=network)
```

## 在沙箱内选择账号

在业务 SDK 的凭证参数中传入以下占位值，再正常调用 SDK：

| 访问身份 | AccessKey ID | AccessKey Secret |
| --- | --- | --- |
| 账号 A | `sandbox-ak-account-a` | `placeholder-secret` |
| 账号 B | `sandbox-ak-account-b` | `placeholder-secret` |

业务 SDK 的 AccessKey ID 必须与 `placeholder` 完全一致，以选择对应账号；AccessKey Secret 使用示例中的占位值。同一账号可访问多个已放行的目标，权限由真实凭证决定。占位 AK 不用于隔离沙箱内不同代码的权限。

## 支持范围

支持 ACS3（V3）、ROA V1、FC 2.0、RPC V1 和 OSS V1/V4，适用于阿里云服务、FC HTTP Trigger 及采用相同签名协议的服务。

- RPC：鉴权参数须放在 URL Query 中；支持 `application/x-www-form-urlencoded` 业务表单。
- OSS：支持 Header 鉴权、预签名 URL 和 PostObject 上传；PostObject 的鉴权表单字段须放在文件字段之前，不支持自定义 CNAME。
