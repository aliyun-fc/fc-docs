# 自带凭证注入

自带凭证注入由您提供真实凭证，通过 `network.rules` 在出网请求上注入或替换 Header。相关限制见[凭证使用限制](./07.凭证使用限制.md)。

## 适用场景

沙箱内代码访问外部服务时需要携带凭证。不应把真实凭证写入沙箱的环境变量或代码，因为沙箱内的代码和依赖都能读取。

`network.rules` 允许把凭证保存在可信的控制端（您的后端、CI Secret 等），创建沙箱时声明访问某域名时把凭证注入到某 Header。沙箱内代码正常发起请求，真实凭证在出网时由平台注入，不进入沙箱。

## 配置沙箱

| 方式 | 适用场景 | 沙箱发出的请求 |
| --- | --- | --- |
| 整 Header 注入 | 控制端能拼出完整 Header，如 `Authorization: Bearer ...` | 可以完全不带这个 Header |
| Header 值占位符替换 | 第三方 SDK 或沙箱代码必须自行拼接 Header，仅需隐藏其中敏感的片段 | 携带 Header 结构和非敏感占位符 |

若两者作用于同一个 Header，平台先替换占位符、再执行整 Header 注入，最终以整 Header 注入的值为准。

### 整 Header 注入

控制端读取真实 Token，创建沙箱时注入到 `Authorization`。

**Node.js**

```typescript
import { Sandbox } from "e2b";

const token = process.env.API_TOKEN;
if (!token) throw new Error("API_TOKEN is required");

const sandbox = await Sandbox.create({
  network: {
    allowOut: ["api.example.com"],   // 放行网络
    denyOut: ["0.0.0.0/0"],
    rules: {                         // 注入凭证
      "api.example.com": [{
        transform: {
          headers: { Authorization: `Bearer ${token}` },
        },
      }],
    },
  },
});
// 沙箱内程序请求 https://api.example.com 时，平台自动注入 Authorization，
// 业务代码不需要再设置这个 Header。
```

**Python**

```python
import os
from e2b import Sandbox

token = os.environ["API_TOKEN"]

sandbox = Sandbox.create(
    network={
        "allow_out": ["api.example.com"],
        "deny_out": ["0.0.0.0/0"],
        "rules": {
            "api.example.com": [
                {"transform": {"headers": {"Authorization": f"Bearer {token}"}}}
            ]
        },
    },
)
```

### Header 值占位符替换

适用于第三方 SDK 必须自行拼接 Header、仅需隐藏其中一段的场景。

当前 E2B SDK 没有独立的 replacement 字段，FC 云沙箱用一个保留 Header 键承载替换规则，值是替换数组的 JSON 字符串：

```text
fc.sandbox.network.header-value-replacements
```

这个键只用来配置规则，不会作为真实 Header 发给目标服务。

**Node.js**

```typescript
import { Sandbox } from "e2b";

const token = process.env.API_TOKEN;
if (!token) throw new Error("API_TOKEN is required");

const replacements = JSON.stringify([
  { placeholder: "TOKEN_PLACEHOLDER", value: token },
]);

const sandbox = await Sandbox.create({
  network: {
    allowOut: ["api.example.com"],
    denyOut: ["0.0.0.0/0"],
    rules: {
      "api.example.com": [{
        transform: {
          headers: {
            "fc.sandbox.network.header-value-replacements": replacements,
          },
        },
      }],
    },
  },
});
```

**Python**

```python
import json, os
from e2b import Sandbox

token = os.environ["API_TOKEN"]
carrier = json.dumps([{"placeholder": "TOKEN_PLACEHOLDER", "value": token}])

sandbox = Sandbox.create(
    network={
        "allow_out": ["api.example.com"],
        "deny_out": ["0.0.0.0/0"],
        "rules": {
            "api.example.com": [
                {"transform": {"headers": {
                    "fc.sandbox.network.header-value-replacements": carrier
                }}}
            ]
        },
    },
)
```

替换规则：大小写敏感；替换同一 Header value 里的所有匹配项；只扫描一次（替换后的新内容不会再触发其他替换）；未命中的占位符会原样发出。

## 验证凭证注入

使用整 Header 注入时，沙箱内直接请求目标服务，无需设置认证 Header：

```bash
curl -i https://api.example.com/v1/resource
```

使用 Header 值占位符替换时，请求中保留 Header 结构和占位符：

```bash
curl -i https://api.example.com/v1/resource \
  -H 'Authorization: Bearer TOKEN_PLACEHOLDER'
```

网关在请求出站时注入或替换真实凭证。
