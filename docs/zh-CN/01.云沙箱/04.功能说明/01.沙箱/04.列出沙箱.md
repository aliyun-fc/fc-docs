# 列出沙箱

列出沙箱用于查看当前账号下仍在运行或可连接的沙箱，适合做运维排查、资源清理和任务恢复。

## 查询沙箱列表

```typescript
import { Sandbox } from "e2b";

const paginator = Sandbox.list({
  apiKey: process.env.E2B_API_KEY,
  apiUrl: process.env.E2B_API_URL,
  domain: process.env.E2B_DOMAIN,
});

while (paginator.hasNext) {
  const sandboxes = await paginator.nextItems();
  for (const sandbox of sandboxes) {
    console.log(sandbox.sandboxId, sandbox.state);
  }
}
```

Python 示例：

```python
import os

from e2b import Sandbox

paginator = Sandbox.list(
    api_key=os.environ["E2B_API_KEY"],
    api_url=os.environ["E2B_API_URL"],
    domain=os.environ["E2B_DOMAIN"],
)

while paginator.has_next:
    for sandbox in paginator.next_items():
        print(sandbox.sandbox_id, sandbox.state)
```

不同 SDK 版本的分页对象形态可能不同。编写业务代码时，建议优先使用 SDK 提供的迭代方式，而不是假设返回值一定是数组。

## 查询当前沙箱信息

```typescript
const info = await sandbox.getInfo();
console.log(info.sandboxId);
console.log(info.templateId);
console.log(info.metadata);
```

Python 示例：

```python
info = sandbox.get_info()
print(info.sandbox_id)
print(info.template_id)
print(info.metadata)
```

## 使用建议

列表接口适合做管理面能力，不建议在高频业务请求中反复调用。业务侧应保存自己的任务 ID 与 `sandboxId` 映射，避免用全量列表反查业务状态。

### `GET /v2/sandboxes`



[官方协议来源](https://docs.e2b.dev/api-reference/sandboxes/list-sandboxes-v2)

**Endpoint:** `GET /v2/sandboxes`

Servers: `https://api.e2b.app`.

Security (upstream OpenAPI): `[{"ApiKeyAuth": []}]`. Scheme details are provided in the linked official contract.

#### 请求参数

| Name | Location | Type | Required | Constraints | Description |
|---|---|---|---|---|---|
| metadata | query | string | no | — | Metadata query used to filter the sandboxes (e.g. "user=abc&app=prod"). Each key and values must be URL encoded. |
| state | query | array of SandboxState | no | — | Filter sandboxes by one or more states |
| order | query | OrderDirection | no | default="desc"; enum=["asc", "desc"] | Sort direction by sandbox start time. Defaults to desc (newest first). |
| startedAfter | query | string | no | format="date-time" | Return sandboxes started at or after this timestamp. |
| template | query | string | no | — | Filter sandboxes by a template ID or alias. |
| nextToken | query | string | no | — | Cursor to start the list from |
| limit | query | integer | no | default=100; minimum=1; maximum=100; format="int32" | Maximum number of items to return per page |

#### 响应

| 状态码 | 说明 | 内容类型 | 结构 |
|---|---|---|---|
| 200 | Successfully returned all running sandboxes | application/json | array of ListedSandbox |
| 400 | Bad request | application/json | Error |
| 401 | Authentication error | application/json | Error |
| 500 | Server error | application/json | Error |

#### 数据结构

##### SandboxState

State of the sandbox

Type: `string`. Constraints: enum=["running", "paused"]. See the official contract linked above.

##### OrderDirection

Sort direction

Type: `string`. Constraints: default="desc"; enum=["asc", "desc"]. See the official contract linked above.

##### ListedSandbox

| 字段 | 类型 / 结构 | 必填 | 约束 | 说明 |
|---|---|---|---|---|
| `templateID` | string | yes | — | Identifier of the template from which is the sandbox created |
| `alias` | string | no | — | Alias of the template |
| `sandboxID` | string | yes | — | Identifier of the sandbox |
| `clientID` | string | yes | deprecated=true | Identifier of the client |
| `startedAt` | string | yes | format="date-time" | Time when the sandbox was started |
| `endAt` | string | yes | format="date-time" | Time when the sandbox will expire |
| `cpuCount` | CPUCount | yes | minimum=1; format="int32" | CPU cores for the sandbox |
| `memoryMB` | MemoryMB | yes | minimum=128; format="int32" | Memory for the sandbox in MiB |
| `diskSizeMB` | DiskSizeMB | yes | minimum=0; format="int32" | Disk size for the sandbox in MiB |
| `metadata` | SandboxMetadata | no | — | — |
| `state` | SandboxState | yes | enum=["running", "paused"] | State of the sandbox |
| `envdVersion` | EnvdVersion | yes | — | Version of the envd running in the sandbox |
| `volumeMounts` | array of SandboxVolumeMount | no | — | — |

##### CPUCount

CPU cores for the sandbox

Type: `integer`. Constraints: minimum=1; format="int32". See the official contract linked above.

##### MemoryMB

Memory for the sandbox in MiB

Type: `integer`. Constraints: minimum=128; format="int32". See the official contract linked above.

##### DiskSizeMB

Disk size for the sandbox in MiB

Type: `integer`. Constraints: minimum=0; format="int32". See the official contract linked above.

##### SandboxMetadata

Type: `object`. Constraints: —. See the official contract linked above.

##### EnvdVersion

Version of the envd running in the sandbox

Type: `string`. Constraints: —. See the official contract linked above.

##### SandboxVolumeMount

|---|---|---|---|---|
| `name` | string | yes | — | Name of the volume |

##### Error
