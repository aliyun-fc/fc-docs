# All-In-One 模板

> **访问说明**：`allow_public_traffic` 默认为 `True`，表示公网 URL **无需流量令牌**即可访问；设为 `False` 时所有公网请求必须携带 `e2b-traffic-access-token` 请求头，query 参数无效。`secure` 默认为 `True`，控制 SDK/envd 控制面鉴权，与流量令牌是两套独立令牌；示例省略默认的 `network` 与 `secure` 参数。公网 URL 应视为访问凭证：未设置应用层鉴权时，持有 URL 的人可完全控制沙箱内浏览器（含已登录态与 Cookie），请勿公开分享，也不要写入日志或前端代码。需要限制访问时，参见[网络访问控制](../../06.网络/05.网络访问控制.md)与[责任共担](../../../06.安全合规/01.责任共担.md)；受限 API Key 在 Enforce 模式下需具有 `sandbox.network.ingress`（Python SDK 只要传 `network` 就会附带发送 `allowPublicTraffic`，故必然置位；JS/TS SDK 与 REST 仅在显式设置 `allowPublicTraffic` 或 `maskRequestHost` 时才置位）与 `sandbox.network.egress`（SDK 默认发送 `allow_internet_access`）权限。受限模式下，服务端客户端可直接在 WebSocket 握手头携带 `e2b-traffic-access-token`（Playwright `connect_over_cdp(headers=)`、Puppeteer `connect({ headers })`、`browser_use` `BrowserSession(headers=)`、Python `websockets`、`wscat`）；只有运行在浏览器页面内的 WebSocket 客户端（如网页版 noVNC）无法自定义握手头，需由受控后端代理注入。

All-In-One 模板在 [browser 模板](01.browser-模板.md)的浏览器能力之上叠加 Code Interpreter 服务，在同一沙箱会话内既能通过 CDP/VNC 驱动云端浏览器，也能执行 Python/JavaScript 代码、处理文件和运行终端命令，适合需要“浏览器自动化 + 代码执行”协同的 AI Agent 场景。

与 browser 模板一样，All-In-One 模板不是开通即用的内置模板，需要先从官方 All-In-One 镜像构建带名称的自定义模板再创建沙箱。本页只描述**相对 browser 模板的差异**：镜像与端口、构建镜像、Code Interpreter 验证，以及组合工作流建议。浏览器能力、健康检查、CDP 探测、noVNC 连接等与 browser 模板一致，见 [browser 模板](01.browser-模板.md)；AIO 场景的完整最佳实践见[使用 AIO Sandbox](../../../05.最佳实践/03.使用%20AIO%20Sandbox.md)。

## 与 browser 模板的差异

| **对比项** | **browser 模板** | **All-In-One 模板** |
| --- | --- | --- |
| 核心定位 | 轻量浏览器自动化环境 | 浏览器自动化 + 代码执行一体化环境 |
| Code Interpreter 服务 | 不支持 | 支持 Python/JavaScript 代码执行、上下文保持与结果返回 |
| 文件处理 | 支持基础文件访问 | 支持文件 API、上下文内读写和处理 |
| 端口 | 3000（浏览器入口） | 3000（浏览器入口）/ 5000（代码与文件入口） |
| 默认镜像 | `runtime/browser`（北京地域示例） | `runtime/all-in-one`（新加坡地域示例） |

## 默认配置

| **配置项** | **默认值** | **说明** |
| --- | --- | --- |
| 容器镜像 | `fc-e2b-registry.ap-southeast-1.cr.aliyuncs.com/runtime/all-in-one:v0.0.52` | 预置一体化沙箱镜像 |
| 浏览器端口 | 3000 | browser 服务监听端口，用于 `/health`、CDP 和 VNC |
| 代码执行端口 | 5000 | Code Interpreter/envd 服务监听端口 |
| CPU | 4 vCPU | 推荐规格，需同时支撑浏览器和代码执行 |
| 内存 | 8192 MB | 推荐规格 |
| 磁盘大小 | 10240 MB | 建议 10 GB 以存储浏览器缓存、截图、下载文件和代码执行结果 |

> **说明**：示例使用新加坡地域镜像。其他地域请将镜像地址中的地域替换为云沙箱接入地域，并保持版本为 `v0.0.52`；`E2B_API_URL`、`E2B_DOMAIN` 也需设为同一地域（SDK 自动读取，无需在方法调用中显式传入）。跨地域镜像构建会失败。本地环境准备和公网连接方式与 [browser 模板](01.browser-模板.md)一致。

镜像内置 noVNC 页面：`https://<sandbox-host>/static/vnc.html?path=/ws/livestream&autoconnect=true`。`path` 不能省略且必须以 `/` 开头（写成相对路径 `ws/livestream` 会解析到 `/static/ws/livestream` 并连接失败；镜像内没有 `defaults.json`），根路径 `/vnc.html` 为 404。默认平台域名（`*.e2b.fc.aliyuncs.com`）会附加 `Content-Disposition: attachment` 响应头，**触发下载而非打开页面**，需先[绑定自定义域名](../../07.FC%20扩展/03.自定义域名.md)；WebSocket 握手不加该响应头，外部 noVNC 客户端仍可直接连 `wss://<sandbox-host>/ws/livestream`（等价别名 `/ws/liveview`）。

## 构建 All-In-One 模板

构建流程与 browser 模板相同，只需替换镜像与模板名称，构建时指定 CPU 与内存规格（推荐 4 vCPU / 8192 MB）。

**Python**：

```python
"""All-In-One 模板构建示例。"""

from dotenv import load_dotenv
from e2b import Template, default_build_logger

load_dotenv()

# SDK 自动读取 E2B_API_KEY / E2B_API_URL / E2B_DOMAIN 环境变量。
FROM_IMAGE = "fc-e2b-registry.ap-southeast-1.cr.aliyuncs.com/runtime/all-in-one:v0.0.52"

build = Template.build(
    Template().from_image(FROM_IMAGE),
    name="my-all-in-one-template",
    cpu_count=4,
    memory_mb=8192,
    on_build_logs=default_build_logger(),
)
print(f"template_id: {build.template_id}")
```

**Node.js**：

```javascript
// All-In-One 模板构建示例。
import { Template, defaultBuildLogger } from 'e2b';

// SDK 自动读取 E2B_API_KEY / E2B_API_URL / E2B_DOMAIN 环境变量。
const FROM_IMAGE =
  'fc-e2b-registry.ap-southeast-1.cr.aliyuncs.com/runtime/all-in-one:v0.0.52';

const build = await Template.build(Template().fromImage(FROM_IMAGE), 'my-all-in-one-template', {
  cpuCount: 4,
  memoryMB: 8192,
  onBuildLogs: defaultBuildLogger(),
});
console.log(`template_id: ${build.templateId}`);
```

## 验证组合能力

浏览器部分（创建沙箱、等待 `/health`、CDP 连接、截图）与 [browser 模板](01.browser-模板.md)完全一致。All-In-One 模板的额外能力是在同一沙箱内通过 Code Interpreter 执行代码：浏览器阶段完成后，用 `run_code` / `runCode` 处理浏览器产物。

**Python**：

```python
# 承接 browser 模板流程中的 sbx（同一沙箱），执行一段 Python 验证代码执行能力。
execution = sbx.run_code(
    "import json\n"
    "print(json.dumps({'status': 'ok', 'source': 'all-in-one'}, ensure_ascii=False))"
)
print("".join(execution.logs.stdout))
```

**Node.js**：

```javascript
// 承接 browser 模板流程中的 sbx（同一沙箱），执行一段 Python 验证代码执行能力。
const execution = await sbx.runCode(
  "import json\nprint(json.dumps({'status': 'ok', 'source': 'all-in-one'}, ensure_ascii=False))",
);
console.log(execution.logs.stdout.join(""));
```

> **说明**：使用 Code Interpreter 时，SDK 需为 `e2b_code_interpreter` / `@e2b/code-interpreter`，沙箱由 `my-all-in-one-template` 创建。

## 使用限制

| **限制项** | **约束** |
| --- | --- |
| 浏览器支持 | 目前内置 Chromium/Chrome 浏览器 |
| 资源规格 | 建议使用 4 vCPU / 8192 MB 或更高规格，避免浏览器和代码执行互相争抢资源 |
| 公网连接 | 默认公网访问无需流量令牌，可直接连接 CDP/VNC；代码执行与文件操作通过 SDK 完成 |
