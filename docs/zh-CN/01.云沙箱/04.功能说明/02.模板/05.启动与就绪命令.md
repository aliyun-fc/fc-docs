# 启动与就绪命令

启动命令（start command）和就绪命令（ready command）是模板构建期的两个命令，用于把 Web 服务等常驻进程固化到模板中：

1. 构建模板时，平台以后台进程执行启动命令，然后反复执行就绪命令，直到就绪命令退出码为 0，判定服务就绪。
2. 服务就绪后，平台对仍在运行的沙箱制作模板快照。基于该模板创建的沙箱在创建时服务已在运行，创建即可访问，不会再次执行启动命令。

如果进程不需要固化到模板，例如每次创建沙箱后要运行的任务都不同，可以不使用模板命令，改为在创建沙箱后运行后台命令，参见下文「在沙箱中运行后台命令」。

## 使用限制

- 仅第二代运行时的模板支持启动命令和就绪命令；第一代模板设置任一命令都会返回 400。第二代运行时需要开通白名单，参见[通过 OpenAPI 构建和管理模板](03.通过%20OpenAPI%20构建和管理模板.md)的「使用第二代运行时」一节。
- 就绪命令退出码为 0 一次即判定就绪，等待就绪有 5 分钟硬超时。启动命令提前退出、就绪命令持续失败或等待超时都会导致模板构建失败，失败原因记录在构建日志中。
- 未设置就绪命令时，平台按默认的端口探测判定就绪；显式设置就绪命令后以就绪命令为准。就绪命令写错时表现为构建就绪超时，而不是请求参数报错，请先在镜像内验证命令正确。
- 使用 `from_template` 从已有模板派生构建时，不能设置启动命令和就绪命令，派生模板继承基座模板的启动命令。

## 通过 E2B SDK 设置

SDK 的 `set_start_cmd` 同时设置启动命令和就绪命令，`set_ready_cmd` 只设置就绪命令。就绪命令可以是任意 Shell 命令字符串，也可以使用 SDK 提供的等待辅助函数：`wait_for_port`、`wait_for_url`、`wait_for_process`、`wait_for_file`、`wait_for_timeout`。

SDK 构建默认使用第一代运行时。使用启动命令和就绪命令时，需要通过 `X-E2B-Template-Alpha-Runtime-Config` 请求头把运行时切换为第二代（`micro-sandbox`）。第二代模板默认磁盘为 60 GiB，要求 CPU 不低于 16 核；使用小规格模板时需在该请求头中显式调小磁盘，例如 `{"runtime": "micro-sandbox", "diskSize": 15360}`。

注意：不要与 `X-E2B-Template-Build-Mode` 等旧版扁平请求头混用。混用后构建请求会走旧链路，`set_start_cmd` 提交的就绪命令会被拒绝（400 `readyCmd is not supported`）。

Python 示例（构建一个预置 HTTP 服务的模板，等待 8000 端口就绪；连接参数的准备见[快速开始](01.快速开始.md)）：

```python
import os
import time

from dotenv import load_dotenv
from e2b import Sandbox, Template, default_build_logger, wait_for_port

load_dotenv()

build = Template.build(
    Template()
    .from_image(os.environ["FROM_IMAGE"])
    # 启动命令在构建期以后台进程执行；就绪命令反复执行，退出码为 0 判定就绪。
    .set_start_cmd("python3 -m http.server 8000", wait_for_port(8000)),
    name=f"template-start-cmd-{int(time.time())}",
    cpu_count=2,
    memory_mb=2048,
    on_build_logs=default_build_logger(),
    # 启动命令和就绪命令仅第二代运行时支持；第二代默认磁盘 60 GiB 要求
    # CPU 不低于 16 核，小规格模板需显式调小磁盘。
    headers={"X-E2B-Template-Alpha-Runtime-Config": '{"runtime": "micro-sandbox", "diskSize": 15360}'},
)

# 模板快照已包含运行中的服务，创建沙箱后即可直接访问。
sandbox = Sandbox.create(template=build.template_id, timeout=900)
try:
    host = sandbox.get_host(8000)
    print(f"https://{host}")
finally:
    sandbox.kill()
```

TypeScript 示例：

```typescript
import { Sandbox, Template, defaultBuildLogger, waitForPort } from "e2b";

const build = await Template.build(
  Template()
    .fromImage(process.env.FROM_IMAGE)
    // 启动命令在构建期以后台进程执行；就绪命令反复执行，退出码为 0 判定就绪。
    .setStartCmd("python3 -m http.server 8000", waitForPort(8000)),
  `template-start-cmd-${Date.now()}`,
  {
    cpuCount: 2,
    memoryMB: 2048,
    onBuildLogs: defaultBuildLogger(),
    // 启动命令和就绪命令仅第二代运行时支持；第二代默认磁盘 60 GiB 要求
    // CPU 不低于 16 核，小规格模板需显式调小磁盘。
    headers: { "X-E2B-Template-Alpha-Runtime-Config": '{"runtime": "micro-sandbox", "diskSize": 15360}' },
  },
);

// 模板快照已包含运行中的服务，创建沙箱后即可直接访问。
const sandbox = await Sandbox.create(build.templateId, { timeoutMs: 900_000 });
try {
  const host = sandbox.getHost(8000);
  console.log(`https://${host}`);
} finally {
  await sandbox.kill();
}
```

## 通过 OpenAPI 设置

调用 `CreateTemplate` 时在 `runtime_config.sandbox_config` 中传入 `start_command` 和 `ready_command`，`generation` 必须为 `2`。完整请求示例参见[通过 OpenAPI 构建和管理模板](03.通过%20OpenAPI%20构建和管理模板.md)。

=== "Python"

    ```python
    models.CreateTemplateSandboxConfig(
        image="<your-image>",
        # 启动命令和就绪命令仅第二代运行时支持。
        generation=2,
        start_command="python3 -m http.server 8000",
        ready_command="curl -sf http://localhost:8000/ > /dev/null",
    )
    ```

=== "TypeScript"

    ```typescript
    new $FCSandbox20260509.CreateTemplateSandboxConfig({
      image: '<your-image>',
      // 启动命令和就绪命令仅第二代运行时支持。
      generation: 2,
      startCommand: 'python3 -m http.server 8000',
      readyCommand: 'curl -sf http://localhost:8000/ > /dev/null',
    })
    ```

## 在沙箱中运行后台命令

不需要固化到模板的常驻进程，可以在创建沙箱后通过后台命令启动。

Python 示例：

```python
server = sandbox.commands.run(
    "python3 -m http.server 8000",
    background=True,
)

host = sandbox.get_host(8000)
print(f"https://{host}")
```

TypeScript 示例：

```typescript
const server = await sandbox.commands.run("python3 -m http.server 8000", {
  background: true,
});

const host = sandbox.getHost(8000);
console.log(`https://${host}`);
```
