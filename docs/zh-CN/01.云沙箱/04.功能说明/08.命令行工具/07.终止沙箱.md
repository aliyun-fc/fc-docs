# 终止沙箱

任务完成后，可以通过 CLI 终止一个或多个沙箱。

```bash
e2b sandbox kill "${SANDBOX_ID:?请设置 SANDBOX_ID}"
```

一次终止多个沙箱：

```bash
e2b sandbox kill "${SANDBOX_ID_1:?请设置 SANDBOX_ID_1}" "${SANDBOX_ID_2:?请设置 SANDBOX_ID_2}" "${SANDBOX_ID_3:?请设置 SANDBOX_ID_3}"
```

终止所有沙箱：

```bash
e2b sandbox kill --all
```

批量终止时，可以按状态或元数据过滤：

```bash
e2b sandbox kill --all --state=running,paused
e2b sandbox kill --all --metadata=key=value
e2b sandbox kill --all --state=running,paused --metadata=key=value
```

终止后，该沙箱不能继续连接或恢复。需要暂停并后续恢复的场景，应使用 SDK 的 `sandbox.pause()` 和 `Sandbox.connect()`。
