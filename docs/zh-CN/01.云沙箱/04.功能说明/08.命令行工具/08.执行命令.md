# 执行命令

使用 CLI 可以在运行中的云沙箱内执行命令，并将输出返回到本地终端：

```bash
e2b sandbox exec "${SANDBOX_ID:?请设置 SANDBOX_ID}" "${COMMAND:?请设置 COMMAND}"
```

例如，列出沙箱当前目录：

```bash
e2b sandbox exec "${SANDBOX_ID:?请设置 SANDBOX_ID}" ls
```

CLI 还支持从标准输入传入内容、后台执行、指定工作目录、指定用户和设置环境变量：

```bash
echo "foo" | e2b sandbox exec "${SANDBOX_ID:?请设置 SANDBOX_ID}" "${COMMAND:?请设置 COMMAND}"
e2b sandbox exec --background "${SANDBOX_ID:?请设置 SANDBOX_ID}" "sleep 60 && echo done"
e2b sandbox exec --cwd /home/user "${SANDBOX_ID:?请设置 SANDBOX_ID}" ls
e2b sandbox exec --user root "${SANDBOX_ID:?请设置 SANDBOX_ID}" apt-get update
e2b sandbox exec --env NODE_ENV=production --env DEBUG=true "${SANDBOX_ID:?请设置 SANDBOX_ID}" node app.js
```

如果需要在服务端代码中执行命令，请使用 SDK 的 Commands：

```typescript
const result = await sandbox.commands.run("echo hello");
console.log(result.stdout.trim());
```

Python 示例：

```python
result = sandbox.commands.run("echo hello")
print(result.stdout.strip())
```
