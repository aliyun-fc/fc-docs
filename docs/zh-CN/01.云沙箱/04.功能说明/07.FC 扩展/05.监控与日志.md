# 监控与日志

监控与日志用于查看 Sandbox 的运行状态和资源使用，也可以将 Sandbox 内程序打印到 stdout / stderr 的日志采集到日志服务。应用侧可以记录 `sandboxId`、任务 ID 和命令结果，便于在云上监控或日志页面中定位问题。

该功能通过函数计算和阿里云可观测能力提供，不属于 E2B SDK 的原生接口。

## 配置入口与生效范围

接入前应先确认监控与日志配置入口和生效范围：

- 配置入口：以当前云沙箱控制台、函数计算控制台或日志服务配置为准；如果控制台未展示云沙箱日志采集入口，请联系产品支持确认开通方式。
- 生效范围：确认配置是对账号、地域、模板、Sandbox 还是会话生效，以及是否只影响新创建的 Sandbox。
- 日志目标：确认日志服务 Project、Logstore、索引字段、保存时间和费用策略。

## 日志采集边界

配置日志采集后，Sandbox 内程序打印到 stdout / stderr 的日志会被采集到日志服务。如果希望任务日志被云上日志服务检索，应让程序直接输出结构化日志，并带上 `sandboxId`、任务 ID 等关联字段。

`sandbox.commands.run()` 返回的 `stdout` / `stderr` 仍会返回给业务代码。业务侧如果需要额外沉淀命令摘要、退出码或错误分类，可以在捕获返回结果后截断、脱敏，并作为应用日志输出。

不要把 E2B SDK 的 Sandbox Logs 兼容接口作为生产日志采集入口。生产排查应依赖业务侧结构化日志、函数计算日志采集、云监控和日志服务中的数据。

## 记录 Sandbox 运行信息

```typescript
import { Sandbox } from "e2b";

const taskId = crypto.randomUUID();

const sandbox = await Sandbox.create("code-interpreter-v1", {
  apiKey: process.env.E2B_API_KEY,
  apiUrl: process.env.E2B_API_URL,
  domain: process.env.E2B_DOMAIN,
  metadata: {
    taskId,
  },
});

try {
  console.log(JSON.stringify({
    event: "sandbox_created",
    taskId,
    sandboxId: sandbox.sandboxId,
  }));

  const result = await sandbox.commands.run("python3 -V", {
    timeoutMs: 30_000,
  });

  console.log(JSON.stringify({
    event: "command_finished",
    taskId,
    sandboxId: sandbox.sandboxId,
    exitCode: result.exitCode,
    stdout: result.stdout.trim(),
    stderr: result.stderr.trim(),
  }));
} finally {
  await sandbox.kill();
}
```

Python 示例：

```python
import json
import os
import uuid

from e2b import Sandbox

task_id = str(uuid.uuid4())

sandbox = Sandbox.create(
    template="code-interpreter-v1",
    api_key=os.environ["E2B_API_KEY"],
    api_url=os.environ["E2B_API_URL"],
    domain=os.environ["E2B_DOMAIN"],
    metadata={
        "taskId": task_id,
    },
)

try:
    print(json.dumps({
        "event": "sandbox_created",
        "taskId": task_id,
        "sandboxId": sandbox.sandbox_id,
    }))

    result = sandbox.commands.run("python3 -V", timeout=30)

    print(json.dumps({
        "event": "command_finished",
        "taskId": task_id,
        "sandboxId": sandbox.sandbox_id,
        "exitCode": result.exit_code,
        "stdout": result.stdout.strip(),
        "stderr": result.stderr.strip(),
    }))
finally:
    sandbox.kill()
```

## 输出结构化日志

配置日志采集后，建议输出结构化日志，便于在日志服务中按字段检索。

```typescript
const result = await sandbox.commands.run(
  `python3 - <<'PY'
import json
import os
import time

task_id = os.environ["TASK_ID"]
print(json.dumps({
    "event": "task_started",
    "taskId": task_id,
    "ts": int(time.time()),
}), flush=True)
print(json.dumps({
    "event": "task_finished",
    "taskId": task_id,
    "ts": int(time.time()),
}), flush=True)
PY`,
  {
    envs: {
      TASK_ID: taskId,
    },
    timeoutMs: 30_000,
  }
);

console.log(result.stdout);
```

Python 示例：

```python
result = sandbox.commands.run(
    """
python3 - <<'PY'
import json
import os
import time

task_id = os.environ["TASK_ID"]
print(json.dumps({
    "event": "task_started",
    "taskId": task_id,
    "ts": int(time.time()),
}), flush=True)
print(json.dumps({
    "event": "task_finished",
    "taskId": task_id,
    "ts": int(time.time()),
}), flush=True)
PY
""",
    envs={
        "TASK_ID": task_id,
    },
    timeout=30,
)

print(result.stdout)
```

## 常见观测对象

- Sandbox 生命周期：创建、连接、暂停、恢复、终止。
- 命令执行结果：退出码、stdout、stderr、耗时。
- 资源使用：CPU、内存、磁盘和网络。
- 关联字段：`sandboxId`、任务 ID、用户或租户标识、模板名称。
- 结构化日志：`event`、`taskId`、`sandboxId`、`exitCode`、`stdout` / `stderr` 摘要。

## 注意事项

- 业务系统应保存任务 ID 与 `sandboxId` 的映射。
- 不要把完整 API Key、AccessKey、数据库密码、OAuth Token 写入日志。
- 长任务建议设置命令超时和 Sandbox 超时。
- 对日志量大的任务，应控制输出大小，避免日志费用过高。

### `GET /v2/sandboxes/{sandboxID}/logs`



[官方协议来源](https://docs.e2b.dev/api-reference/sandboxes/get-sandbox-logs-v2)

**Endpoint:** `GET /v2/sandboxes/{sandboxID}/logs`

Servers: `https://api.e2b.app`.

Security (upstream OpenAPI): `[{"ApiKeyAuth": []}]`. Scheme details are provided in the linked official contract.

#### 请求参数

| Name | Location | Type | Required | Constraints | Description |
|---|---|---|---|---|---|
| sandboxID | path | string | yes | — | — |
| cursor | query | integer | no | minimum=0; format="int64" | Starting timestamp of the logs that should be returned in milliseconds |
| limit | query | integer | no | default=1000; minimum=0; maximum=1000; format="int32" | Maximum number of logs that should be returned |
| direction | query | LogsDirection | no | enum=["forward", "backward"] | Direction of the logs that should be returned |
| level | query | LogLevel | no | — | Minimum log level to return. Logs below this level are excluded |
| search | query | string | no | maxLength=256 | Case-sensitive substring match on log message content |

#### 响应

| 状态码 | 说明 | 内容类型 | 结构 |
|---|---|---|---|
| 200 | Successfully returned the sandbox logs | application/json | SandboxLogsV2Response |
| 401 | Authentication error | application/json | Error |
| 404 | Not found | application/json | Error |
| 500 | Server error | application/json | Error |

#### 数据结构

##### LogsDirection

Direction of the logs that should be returned

Type: `string`. Constraints: enum=["forward", "backward"]. See the official contract linked above.

##### LogLevel

Severity level for log entries (e.g. info, warn, error)

Type: `string`. Constraints: —. See the official contract linked above.

##### SandboxLogsV2Response

| 字段 | 类型 / 结构 | 必填 | 约束 | 说明 |
|---|---|---|---|---|
| `logs` | array of SandboxLogEntry | yes | default=[] | Sandbox logs structured |

##### SandboxLogEntry

| 字段 | 类型 / 结构 | 必填 | 约束 | 说明 |
|---|---|---|---|---|
| `timestamp` | string | yes | format="date-time" | Timestamp of the log entry |
| `message` | string | yes | — | Log message content |
| `level` | LogLevel | yes | — | Severity level for log entries (e.g. info, warn, error) |
| `fields` | object | yes | — | — |

##### Error

| 字段 | 类型 / 结构 | 必填 | 约束 | 说明 |
|---|---|---|---|---|
| `code` | integer | yes | format="int32" | Error code |
| `error_code` | string | no | — | Machine-readable semantic error code. Not a closed set; initial values: sandbox_capacity_unavailable, sandbox_placement_timeout, sandbox_no_compatible_node, sandbox_create_failed, internal_server_error. |
| `message` | string | yes | — | Error |
