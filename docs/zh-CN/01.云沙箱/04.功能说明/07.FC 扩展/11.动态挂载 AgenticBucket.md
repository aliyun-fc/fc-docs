# 动态挂载 AgenticBucket

动态挂载 AgenticBucket 用于在创建 Sandbox 时，将 AgenticBucket 下的 BucketSpace 挂载到 Sandbox 内的本地目录。挂载完成后，Sandbox 可以像访问本地文件系统一样读取或写入挂载目录。

如需向运行中的 Sandbox 追加 AgenticBucket 挂载，请参见[追加挂载沙箱存储](./09.追加挂载沙箱存储.md)。

AgenticBucket 动态挂载通过 Sandbox metadata 配置，不需要把挂载配置固化到模板中。创建 Sandbox 时传入：

- `fc.sandbox.storage.agenticbucket`：AgenticBucket 挂载配置，值为 JSON 字符串。
- `fc.sandbox.auth.role`：用于访问 AgenticBucket 的 RAM Role ARN。

## 前提条件

AgenticBucket 的产品说明和资源管理方式参见[AgenticBucket 概述](https://help.aliyun.com/zh/oss/user-guide/agentic-bucket-overview)。

使用前需要准备：

- AgenticBucket 完整名称。
- BucketSpace 完整名称。
- AgenticBucket 所在地域的 OSS Endpoint。同地域访问建议使用内网 Endpoint，例如 `https://oss-<region>-internal.aliyuncs.com`。
- RAM Role ARN。该角色需要授予函数计算服务可扮演权限，并具备目标 AgenticBucket 和 BucketSpace 的读写权限。
- Sandbox 内挂载目录，例如 `/mnt/agentic-bucket`。

## 挂载配置

`fc.sandbox.storage.agenticbucket` 的值是 JSON 字符串，结构如下：

```json
{
  "mountPoints": [
    {
      "agenticBucket": "<agentic-bucket-full-name>",
      "bucketName": "<bucket-space-full-name>",
      "mountDir": "/mnt/agentic-bucket",
      "bucketPath": "/",
      "endpoint": "https://oss-<region>-internal.aliyuncs.com",
      "readOnly": false
    }
  ]
}
```

字段说明：

| 字段 | 是否必填 | 说明 |
| --- | --- | --- |
| `mountPoints` | 是 | AgenticBucket 挂载点列表。 |
| `agenticBucket` | 是 | AgenticBucket 完整名称。 |
| `bucketName` | 是 | BucketSpace 完整名称。 |
| `mountDir` | 是 | Sandbox 内的挂载目录，必须是绝对路径，例如 `/mnt/agentic-bucket`。 |
| `bucketPath` | 否 | BucketSpace 内路径；缺失时默认为 `/`。 |
| `endpoint` | 是 | OSS Endpoint，应与 AgenticBucket 所在地域匹配。 |
| `readOnly` | 否 | 是否只读挂载；缺失时默认为 `false`。 |

## 创建带 AgenticBucket 挂载的 Sandbox

创建 Sandbox 的基本方法参见[创建沙箱](../01.沙箱/02.创建沙箱.md)。以下 Python 示例在创建 Sandbox 时动态挂载 AgenticBucket，并验证文件读写。将代码保存为 `11_sandbox_agentic_bucket.py`：

```python
import json
import os

from e2b import Sandbox


def require_env(name: str) -> str:
    value = os.environ.get(name, "").strip()
    if not value:
        raise RuntimeError(f"缺少环境变量: {name}")
    return value


mount_dir = "/mnt/agentic-bucket"
marker_path = f"{mount_dir}/hello-agentic-bucket.txt"
agentic_bucket_config = {
    "mountPoints": [
        {
            "agenticBucket": require_env("AGENTIC_BUCKET_NAME"),
            "bucketName": require_env("BUCKET_SPACE_NAME"),
            "mountDir": mount_dir,
            "bucketPath": "/",
            "endpoint": require_env("OSS_ENDPOINT"),
            "readOnly": False,
        }
    ]
}

sandbox = None
try:
    sandbox = Sandbox.create(
        template=require_env("E2B_TEMPLATE"),
        timeout=300,
        api_key=require_env("E2B_API_KEY"),
        api_url=require_env("E2B_API_URL"),
        domain=require_env("E2B_DOMAIN"),
        metadata={
            "fc.sandbox.storage.agenticbucket": json.dumps(agentic_bucket_config),
            "fc.sandbox.auth.role": require_env("FCSANDBOX_ROLE_ARN"),
        },
    )

    sandbox.files.write(marker_path, "hello agentic bucket\n")
    content = sandbox.files.read(marker_path)
    if content != "hello agentic bucket\n":
        raise RuntimeError(f"文件内容不一致: {content!r}")
finally:
    if sandbox is not None:
        sandbox.kill()

print("AgenticBucket 动态挂载读写验证成功")
```

运行前设置环境变量：

```bash
export E2B_API_KEY="<your-e2b-api-key>"
export E2B_API_URL="https://api.<region>.e2b.fc.aliyuncs.com"
export E2B_DOMAIN="<region>.e2b.fc.aliyuncs.com"
export E2B_TEMPLATE="<template-id>"

export AGENTIC_BUCKET_NAME="<agentic-bucket-full-name>"
export BUCKET_SPACE_NAME="<bucket-space-full-name>"
export OSS_ENDPOINT="https://oss-<region>-internal.aliyuncs.com"
export FCSANDBOX_ROLE_ARN="acs:ram::<account-id>:role/<execution-role>"

python 11_sandbox_agentic_bucket.py
```

## 使用限制

- AgenticBucket、BucketSpace、OSS Endpoint 和 Sandbox 应使用匹配的地域与网络环境。
- 同地域访问建议使用 AgenticBucket 所在地域的 OSS 内网 Endpoint，不需要额外配置 VPC。
- 单次创建 Sandbox 请求中的普通 OSS 与 AgenticBucket 挂载点合计不能超过 5 个。
- 挂载目录必须是规范化的绝对 Unix 路径，不能为 `/`，不能包含前后空格或 `..`。
- 同一个 Sandbox 中的挂载目录不能重复。
- 只读挂载只能读取挂载路径内的文件。
