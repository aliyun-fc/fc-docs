# 运行命令

Commands 用于在 Sandbox 中执行命令或进程，是 Agent 工具调用、代码执行和环境检查的基础能力。

## 运行命令

运行一条命令并读取 stdout：

Python 示例：

```python
result = sandbox.commands.run("ls -lh /")
print(result.stdout.strip())
```

TypeScript 示例：

```typescript
const result = await sandbox.commands.run("ls -lh /");
console.log(result.stdout.trim());
```

## 已兼容方法

- `sandbox.commands.run()`：启动进程并等待结果。
- `sandbox.commands.list()`：列出运行中的进程。
- `sandbox.commands.connect()`：连接到已有进程。
- `sandbox.commands.sendStdin()`：发送标准输入。
- `sandbox.commands.kill()`：终止进程。

交互式终端和依赖 TTY 的任务使用独立的 `sandbox.pty` API，参见 [PTY](07.PTY.md)。

## 命令 SDK 参数与返回值

| Python / TypeScript | 含义 |
| --- | --- |
| `cmd` | 要执行的命令字符串|
| `background` | 前台返回 `CommandResult`；后台返回 `CommandHandle`|
| `envs`, `user`, `cwd` | 命令环境变量、运行用户、工作目录|
| `on_stdout` / `onStdout`, `on_stderr` / `onStderr` | 输出回调|
| `stdin` | 开启后才能发送标准输入|
| `timeout` / `timeoutMs` | Python 秒，TS 毫秒；Python 默认 60 秒，`0` 不限制连接时长|
| `request_timeout` / `requestTimeoutMs` | Python 2.37.1 的流式 `run/connect` 不应用此参数，建连和流均由 `timeout` 控制|

`CommandResult` 包含 `stdout`、`stderr` 和退出码（Python `exit_code` / TS `exitCode`）。Python `CommandHandle.wait()` 在非零退出码时抛出 `CommandExitException`；应区分进程失败和请求超时。

[Python SDK 2.37.1 参数依据](https://docs.e2b.dev/sdk-reference/python-sdk/v2.37.1/sandbox_sync)
