# Teams and Subscription Plans

A Team is a workspace in FC Agent Sandbox. It owns the subscription plan and resource group assignment. You can create multiple Teams under the same account for different businesses, environments, or permission scopes. API keys, templates, and sandboxes belong to a Team. When you create an API key, you must select a Team, and sandboxes created with that key also belong to the selected Team.

The subscription plan belongs to the Team and determines the capabilities available to sandboxes under that Team. To limit the total CPU and memory available to a Team, see [Team Quota Management](https://www.alibabacloud.com/help/en/functioncompute/quota-management). For API key creation and usage, see [Create an API Key](https://www.alibabacloud.com/help/en/functioncompute/create-api-key).

## Prerequisites

Before you create or manage Teams, make sure that:

- Function Compute is activated for your account.
- FC Agent Sandbox is activated for your account.
- Your Alibaba Cloud account or RAM user has permission to manage FC Agent Sandbox Teams.
- If you need to split resources by business, you have already created resource groups in the [Resource Management console](https://resourcemanager.console.aliyun.com) and granted the required permissions to RAM users.

## Teams, resource groups, subscription plans, and API keys

| Object | Description |
|--------|-------------|
| Team | An FC Agent Sandbox workspace. Subscription plans, resource group ownership, and quotas are managed at the Team level. |
| Resource group | An Alibaba Cloud resource grouping and RAM authorization boundary. You select a resource group when creating a Team. One resource group can contain multiple Teams. |
| Subscription plan | The capability tier of a Team. For plan differences, see [Feature differences in the multi-version subscription plan for cloud sandboxes](https://www.alibabacloud.com/help/en/functioncompute/feature-differences-in-the-multi-version-subscription-plan-for-cloud-sandboxes). |
| API key | A data-plane credential. Each API key is bound to one Team and inherits that Team's subscription plan and resource group context. |

The relationship is as follows:

```text
Resource group
└── Team
    ├── Subscription plan
    ├── API key
    ├── Template
    └── Sandbox
```

- You must select a Team when creating an API key. After creation, you cannot rebind the key to another Team.
- Templates and sandboxes under the same Team follow that Team's subscription plan.
- The console filters instances, templates, and API keys by resource group and Team.

## Create a Team

1. Log on to the Function Compute console and open any FC Agent Sandbox page, such as [API Keys](https://fcnext.console.aliyun.com/cn-beijing/sandbox-api-keys), [Instances](https://fcnext.console.aliyun.com/cn-beijing/sandbox-instances), [Templates](https://fcnext.console.aliyun.com/cn-beijing/sandbox-templates), or [Domains](https://fcnext.console.aliyun.com/cn-beijing/sandbox-domains).
2. Confirm the resource group in the upper-left corner of the page. The resource group affects the Team list scope and is prefilled when you create a Team.
3. In the Team selector at the top of the left navigation pane, click **Create Team**. You can also click **Create Team** in the **Manage Team** drawer or in the Create API Key form.
4. In the creation dialog box, complete the configuration and click **Confirm**.

| Parameter | Required | Description |
|-----------|----------|-------------|
| Team name | Yes | Cannot be changed after creation. The name can contain letters and digits, separated by spaces, underscores (`_`), hyphens (`-`), or periods (`.`). Use a traceable name such as `agent-prod` or `eval-test`. |
| Resource group | Yes | The Alibaba Cloud resource group that the Team belongs to. The current console resource group is selected by default. If none is selected, the account default resource group is usually prefilled. |
| Subscription plan | Yes | The Team and its resources inherit this plan. The default is Pro. Downgrade is not supported after creation. In regions where multi-plan selection is not available, this field is hidden and the system creates the Team with Pro. |
| Description | No | Up to 100 characters. Describe the purpose of the Team. |

After the Team is created, you can view the Team name and Team ID in the Team selector and the management drawer. Before you create an API key or view instances and templates, confirm that the currently selected Team is correct.

## Subscription plans

The subscription plan determines the capabilities available to sandboxes under a Team. When you create a Team in the console, Pro is selected by default. After creation, you can only upgrade to a higher plan. Downgrade is not supported in the console. If you need a lower plan, create a new Team or contact product support.

For capability differences, typical scenarios, and billing details by plan, see [Feature differences in the multi-version subscription plan for cloud sandboxes](https://www.alibabacloud.com/help/en/functioncompute/feature-differences-in-the-multi-version-subscription-plan-for-cloud-sandboxes). For billing rules, see [Pay-as-you-go](https://www.alibabacloud.com/help/en/functioncompute/pay-as-you-go-of-fc-agent-sandbox).

If a request exceeds the capabilities allowed by the current subscription plan, such as an unsupported timeout or hibernation operation, the request fails. Adjust the request parameters or upgrade the Team's subscription plan.

## Manage Teams

1. Open any FC Agent Sandbox page.
2. In the Team selector, click **Manage Team**.
3. In the management drawer, view the Team ID, name, plan, description, resource group, owner, and creation time. You can also search by Team name or owner UID.

Supported operations:

| Operation | Description |
|-----------|-------------|
| Create Team | Same as the creation flow above. |
| Upgrade | Upgrade the subscription plan to a higher tier. The upgrade path is Eco → Std → Pro → Ent. Downgrade is not supported. |
| Delete | Before deletion, the console shows the number of related API keys, sandboxes, and templates. You cannot delete a Team that still has API keys. Clean up the keys on the API Keys page first. |

The console does not currently support editing the Team name or description, or changing the Team's resource group. Confirm the name and resource group when you create the Team.

## Select a Team when creating an API key

1. Open the [FC Agent Sandbox API Keys page](https://fcnext.console.aliyun.com/cn-beijing/sandbox-api-keys).
2. Click **Create API Key**.
3. Select a **Team** in the form. The list is filtered by the current resource group. If no Team exists under the current resource group, you can create one from the form.
4. Enter a description and expiration time, and then complete creation.

The API key is bound to the selected Team. Sandboxes created with that key through the SDK or CLI belong to the corresponding Team and are constrained by that Team's subscription plan. For the full creation steps and security recommendations, see [Create an API Key](https://www.alibabacloud.com/help/en/functioncompute/create-api-key).

## Recommendations

- Split Teams by business, environment, or project. For example, use separate Teams for production, testing, and evaluation.
- If you need RAM-based isolation, plan resource groups first, and then create Teams under the corresponding resource groups.
- Split API keys by Team. Do not share one long-lived key across multiple environments or businesses.
- If you need to limit the total CPU or memory available to a Team, record the Team ID and configure Team quotas. See [Team Quota Management](https://www.alibabacloud.com/help/en/functioncompute/quota-management). Use the Team ID as `TagValue`.

## FAQ

### Do I need a Team before creating an API key?

Yes. You must select a Team when creating an API key. If no Team exists under the target resource group, create one first, or create a Team directly from the Create API Key form.

### How do I get a Team ID?

Open **Manage Team** in the Team selector. You can copy the Team ID from the list. When you configure Team quotas, set this value as `TagValue`.

### Why is the subscription plan not shown when I create a Team?

Multi-version subscription plans are enabled by region. In regions where the feature is not available, the plan selector is hidden and the system creates the Team with Pro. The Ent plan appears only after it is enabled for the account.

### Can I move an existing Team to another resource group?

The console does not currently support changing a Team's resource group. Select the correct resource group when you create the Team. To change ownership, create a new Team under the target resource group and switch the corresponding API keys and traffic.

### What should I do if deleting a Team fails because API keys still exist?

You cannot delete a Team that still has API keys. Delete the related keys on the API Keys page first, and then delete the Team. Before deletion, confirm that the Team no longer has business resources that you need to keep.

### Are FC Agent Sandbox Teams managed through the E2B SDK?

No. FC Agent Sandbox Teams are created and managed in the Function Compute console. They are not managed through the E2B SDK Team API. Day-to-day access still uses the E2B SDK to create and operate sandboxes. Identity comes from the FC Agent Sandbox API key and the Team bound to that key.
