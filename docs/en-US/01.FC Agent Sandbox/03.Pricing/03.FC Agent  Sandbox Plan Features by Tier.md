# FC Agent  Sandbox Plan Features by Tier
## Multi-tier Subscription Plans: Target Customers & Scenarios
| Plan | Target Customers | Typical Scenarios | Compute Stability & Performance |
|------|---------|---------|---------|
| Eco | AI Startups、<br>Individual Developers | **Agent Exploration & Functional Testing:**：<br>Single-step debugging, Tool Use chain verification, low-frequency asynchronous long-running tasks. | **Lowest Barrier to Entry**：<br>Cost-effective choice; allows for minor compute fluctuations. |
| Stad(Recommended) | Mid-market Enterprises <br> AI SaaS Providers | **Enterprise Copilots & Productivity Tools:**：<br>Daily office assistants, data analysis (Code Interpreter), document parsing & format conversion.<br>**Large-scale Offline Sampling & Parallel Training:**：<br>Cost-effective for high-volume tasks; tolerates second-level cold starts; provides massive low-cost sandboxes. | **Balanced & General-purpose:**：<br>Stable performance with low-latency response; suitable for enterprise-grade production workloads. |
| Pro(Recommended) | Top-tier AI Application Enterprises,MaaS/Agent Platforms | **High-concurrency C-side Agent Apps:**：<br>Multi-agent collaboration, code execution for massive concurrent users, and heavy complex computations.<br>**Large-scale Online RL Simulation:**：<br>Instant provisioning of massive sandbox environments; supports ultra-low latency, high concurrency, and high-throughput RL environment sampling & simulation. |**Elastic High Throughput:**：<br>Supports million-level sandbox concurrency with ultra-low latency.<br>Ideal for high-concurrency Agent code execution and large-scale distributed high-throughput RL sampling.|

* 注：<br>
1.**高并发深休眠唤醒效率**：指在2C4G规格，万级并发场景下，完成深休眠实例恢复以及网络重建的总耗时。<br>
2.**深休眠**：对标E2B Pause/Resume功能，沙箱未暂停时最大存活时长：Eco/Std 24小时，Pro 7天。暂停后计时器自动清零，恢复后重新获得完整时长。通过“暂停-恢复-暂停-恢复”循环，实现无限期在线。<br>
3.**浅休眠**：Pro版独有。基于请求感知与内存快照技术，当实例空闲（CPU消耗 < 0.01core / 网络流量< 1,000 Bytes/s /无请求）时自动进入浅休眠以降低成本(浅休眠状态CPU不计费）；有请求时 1ms 极速唤醒。<br>
> 多版本订阅计划的功能差异后续还会继续演进，敬请期待～

## 订阅计划管理
**购买与计费**：免开通，按量后付费。创建/管理Team时设置订阅计划，可选设置Eco/Std/Pro版本。<br>
**生效机制**：订阅计划属性由 Team 层级向下继承。当前Team 下的所有 Template 和 Sandbox 均自动同步该计划属性，保持全局一致。<br>
**变更和管理**：<br>
* 升级：支持单向平滑升级（Eco → Std → Pro），可在 Team 设置中直接操作。<br>
* 降级：为避免功能缩减影响存量业务，暂不支持在线降级。如需降级，请新建 Team 或联系技术支持（钉钉群：179855020297）。<br>
