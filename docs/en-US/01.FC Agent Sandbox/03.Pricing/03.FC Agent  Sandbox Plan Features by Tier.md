* Notes：<br>
1.**Deep Hibernation Resume Efficiency under High Concurrency**: Refers to the total time required to restore Deep Hibernation instances and rebuild network connections in a high-concurrency scenario (10,000+ concurrent requests) with a 2C4G instance specification.<br>
2.**Deep Hibernation**: Comparable to E2B's Pause/Resume functionality. The maximum lifetime for an active (unpaused) sandbox is 24 hours for Eco/Std/Pro plan. The timer automatically resets upon pausing, granting the full duration again upon resumption.By cycling through "pause-resume-pause-resume," the sandbox's online duration can be continuously extended.<br>
3.**Light Hibernation**: Exclusive to the Pro plan. Leveraging request-awareness and memory snapshot technologies, instances automatically enter shallow sleep when idle (CPU usage < 0.01 core / Network traffic < 1,000 Bytes/s / No incoming requests) to reduce costs (No vCPU charges are incurred during shallow sleep; memory and disk storage continue to be billed according to standard rates). Instances are woken up ultra-fast within 1 ms upon receiving new requests.<br>
4.**Maximum lifetime**:The default is 24 hours for Eco, Std, and Pro tiers. To request an extension, please submit a support ticket. The platform automatically supports existing Pro instances that exceed this time limit.<br>
5.**Maximum Retention Duration in Deep Sleep State**:The default is 7 days for Eco, Std, and Pro tiers. To request an extension, please submit a support ticket. The platform automatically supports existing Pro instances that exceed this time limit.

## Subscription Plan Management
**Purchase & Billing**：No activation required; billed on a pay-as-you-go basis. Set the subscription plan when creating or managing a Team, with options for Eco, Std, or Pro tiers.<br>
**Activation Mechanism**: Subscription plan attributes are inherited from the Team level downwards. All Templates and Sandboxes under the current Team automatically synchronize with these plan attributes, ensuring global consistency.<br>
**Changes & Management**：<br>
* Upgrade/Downgrade: Supports seamless one-way upgrades (Eco → Std → Pro) and downgrades (Pro → Std → Eco), which can be performed directly in Team Settings.After downgrading, in addition to a decrease in compute QoS, the Light Sleep feature will also become ineffective when downgrading from Pro to Std.<br>
