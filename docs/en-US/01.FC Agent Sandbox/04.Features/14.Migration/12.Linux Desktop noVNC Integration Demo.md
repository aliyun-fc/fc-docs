# Linux Desktop noVNC Integration Demo

## Code

### demo.py (backend Python: sandbox lifecycle + HTTP service)

```python
"""Linux Desktop + noVNC WebSDK integration demo (backend).

Three files ship together: demo.py (this file), index.html (frontend), and .env (credentials); see README.md for instructions.

Dependencies: pip install "e2b>=2.31.0" e2b-desktop==2.4.1 python-dotenv
Run: python demo.py   (open the printed http://127.0.0.1:<port>/ in a browser to see the live desktop)
"""
from __future__ import annotations

import json
import os
import signal
from http.server import BaseHTTPRequestHandler, ThreadingHTTPServer
from pathlib import Path

from dotenv import load_dotenv
from e2b import Template, default_build_logger
from e2b_desktop import Sandbox

BASE_DIR = Path(__file__).resolve().parent
load_dotenv(BASE_DIR / ".env")

TEMPLATE = os.environ["E2B_DESKTOP_TEMPLATE"]
IMAGE = os.environ.get("E2B_DESKTOP_IMAGE", "")
HOST = "127.0.0.1"


def ensure_template() -> str:
    if Template.exists(TEMPLATE):
        print(f"[demo] reuse template: {TEMPLATE}", flush=True)
        return TEMPLATE
    if not IMAGE:
        raise SystemExit(
            f"[demo] template {TEMPLATE!r} does not exist; set E2B_DESKTOP_IMAGE in .env to build it automatically"
        )
    print(f"[demo] build template {TEMPLATE!r} from image: {IMAGE}", flush=True)
    build = Template.build(
        Template().from_image(IMAGE),
        name=TEMPLATE,
        cpu_count=4,
        memory_mb=8192,
        on_build_logs=default_build_logger(),
    )
    return build.template_id


class Handler(BaseHTTPRequestHandler):
    stream_url: str = ""

    def do_GET(self) -> None:
        if self.path == "/api/sandbox/vnc-url":
            body = json.dumps({"streamUrl": Handler.stream_url}).encode("utf-8")
            self.send_response(200)
            self.send_header("Content-Type", "application/json")
            self.send_header("Content-Length", str(len(body)))
            self.end_headers()
            self.wfile.write(body)
            return
        if self.path in ("/", "/index.html"):
            body = (BASE_DIR / "index.html").read_bytes()
            self.send_response(200)
            self.send_header("Content-Type", "text/html; charset=utf-8")
            self.send_header("Content-Length", str(len(body)))
            self.end_headers()
            self.wfile.write(body)
            return
        if self.path == "/favicon.ico":
            self.send_response(204)
            self.end_headers()
            return
        self.send_error(404)

    def log_message(self, *args) -> None:
        pass  # no access log, so no URL (including query parameters) is written to disk


def _stop(_signum, _frame) -> None:
    raise KeyboardInterrupt


def main() -> None:
    signal.signal(signal.SIGTERM, _stop)

    template = ensure_template()
    print("[demo] creating desktop sandbox (Xvfb + xfce4 + x11vnc + noVNC)...", flush=True)
    desktop = Sandbox.create(template=template, timeout=600, secure=True)
    server: ThreadingHTTPServer | None = None
    try:
        desktop.stream.start()
        stream_url = desktop.stream.get_url()
        # If the data plane requires a traffic access token, append it as a query parameter here:
        # token = getattr(desktop, "traffic_access_token", None)
        # if token:
        #     stream_url += f"&token={token}"

        Handler.stream_url = stream_url
        server = ThreadingHTTPServer((HOST, 0), Handler)
        print(f"[demo] open in browser: http://127.0.0.1:{server.server_port}/", flush=True)
        print("[demo] Ctrl-C to exit (stops the stream and destroys the sandbox)", flush=True)
        server.serve_forever()
    except KeyboardInterrupt:
        print("\n[demo] exiting...", flush=True)
    finally:
        if server is not None:
            server.server_close()
        try:
            desktop.stream.stop()
        except Exception:
            pass
        desktop.kill()
        print("[demo] VNC stream stopped and sandbox destroyed", flush=True)


if __name__ == "__main__":
    main()
```

### index.html (frontend HTML: noVNC CDN ESM direct rendering)

```html
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>FC Linux Desktop (noVNC)</title>
  <style>
    html, body { margin: 0; height: 100%; }
    #vnc-screen { width: 100vw; height: 100vh; }
  </style>
</head>
<body>
  <div id="vnc-screen"></div>

  <script type="module">
    // ESM import of the official noVNC build (pinned version; the npm package's lib/rfb.js is CJS,
    // so it cannot be loaded directly with <script src>)
    import RFB from 'https://cdn.jsdelivr.net/gh/novnc/noVNC@v1.6.0/core/rfb.js';

    async function initVNC() {
      // Get stream_url from the backend API (sandbox lifecycle and credentials stay in the backend,
      // the frontend never touches them)
      const resp = await fetch('/api/sandbox/vnc-url');
      const { streamUrl } = await resp.json();

      const rfb = new RFB(
        document.getElementById('vnc-screen'),
        // https://{sandbox-host}/vnc.html?... — one URL, two roles:
        // opening it in a browser serves the noVNC page; RFB upgrades it to
        // wss://.../vnc.html as the WebSocket endpoint
        streamUrl,
        { credentials: { password: '' } }  // empty when stream.start() has auth disabled
      );

      rfb.scaleViewport = true;
      rfb.resizeSession = false;
    }

    initVNC();
  </script>
</body>
</html>
```

## Data flow

```
Browser (index.html, noVNC CDN ESM)
  │  GET /api/sandbox/vnc-url ──→ demo.py (returns only streamUrl)
  │  RFB connects directly to wss://{sandbox-host}/vnc.html ──→ websockify ──→ x11vnc ──→ Xvfb desktop
  └─ Rendering + mouse/keyboard input (data plane does not go through the backend)
```

## Run

```bash
pip install "e2b>=2.31.0" e2b-desktop==2.4.1 python-dotenv
# 1. Fill E2B_API_KEY and the other values in .env with real values
python demo.py
# 2. Open the printed http://127.0.0.1:<random-port>/ in a browser to see and control the live desktop
# 3. Ctrl-C to exit (stops the VNC stream and destroys the sandbox automatically)
```

## Verification records

- Backend API: `/api/sandbox/vnc-url` returns a streamUrl that starts with `https://` and contains `/vnc.html`; `/` returns the page normally.
- Exit: SIGTERM/Ctrl-C stops the VNC stream and destroys the sandbox automatically.
- Frontend: RFB connection, screen rendering, and live desktop refresh verified in a real Chrome.
