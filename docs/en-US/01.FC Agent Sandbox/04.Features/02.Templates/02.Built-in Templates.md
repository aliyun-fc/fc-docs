# Built-in Templates

FC Agent Sandbox provides and maintains built-in templates for quickly creating standard sandboxes. The current built-in templates cover basic command and file access and code execution.

Use a built-in template first when you need general capabilities such as Python, Node.js, file management, or code execution. Build a custom image template only when the built-in templates cannot meet your requirements for application dependencies, system libraries, runtime versions, or enterprise standards.

## Template list

| Template | Use case | Description |
| --- | --- | --- |
| [base template](02.Built-in%20Templates/01.Base%20Template.md) | Basic commands, file access, SDK connectivity checks | Default base template; does not provide the Code Interpreter service |
| [code-interpreter-v1 template](02.Built-in%20Templates/02.Code%20Interpreter%20v1%20Template.md) | AI Agent code execution, data analysis, file processing | The quickstart and Code Interpreter examples use `code-interpreter-v1` by default |

> **Note**
>
> `base` and `code-interpreter-v1` are automatically ready after FC Agent Sandbox is activated. You can create a sandbox directly by template name. Browser, All-In-One, Desktop, Claude Code, OpenClaw, and other templates must be built from their official images. See [Other Templates](07.Other%20Templates.md).

## View templates

Use the CLI to view the templates available to the current account:

```bash
export E2B_API_KEY="<your-api-key>"
export E2B_API_URL="https://api.cn-beijing.e2b.fc.aliyuncs.com"
export E2B_DOMAIN="cn-beijing.e2b.fc.aliyuncs.com"

e2b template list
```

## Create a sandbox from a template

When you use the `e2b_code_interpreter` SDK, it creates a `code-interpreter-v1` sandbox by default, so you usually do not need to specify the template.

When you use the generic `e2b` SDK, select a template explicitly through the `template` parameter. The SDK automatically reads the `E2B_API_KEY`, `E2B_API_URL`, and `E2B_DOMAIN` environment variables. Python example:

```python
from e2b import Sandbox

sandbox = Sandbox.create(template="code-interpreter-v1")
```

TypeScript example:

```typescript
import { Sandbox } from "e2b";

const sandbox = await Sandbox.create("code-interpreter-v1");
```
