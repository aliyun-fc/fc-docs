# Run Commands

Commands is the basic capability for running commands or processes in FC Agent Sandbox. It underpins agent tool calls, code execution, and environment checks.

## Run a command

Run a command and read `stdout`:

```python
result = sandbox.commands.run("ls -lh /")
print(result.stdout.strip())
```

TypeScript example:

```typescript
const result = await sandbox.commands.run("ls -lh /");
console.log(result.stdout.trim());
```

## Compatible methods

- `sandbox.commands.run()`: Start a process and wait for the result.
- `sandbox.commands.list()`: List running processes.
- `sandbox.commands.connect()`: Connect to an existing process.
- `sandbox.commands.sendStdin()`: Send standard input.
- `sandbox.commands.kill()`: Stop a process.

Interactive terminals and tasks that depend on TTY should use the dedicated `sandbox.pty` API. For details, see [PTY](07.PTY.md).

## Command SDK parameters and results

| Python / TypeScript | Meaning |
| --- | --- |
| `cmd` | Command string. |
| `background` | Foreground returns `CommandResult`; background returns `CommandHandle`. |
| `envs`, `user`, `cwd` | Command environment, execution user, working directory. |
| `on_stdout` / `onStdout`, `on_stderr` / `onStderr` | Output callbacks. |
| `stdin` | Enable before sending standard input. |
| `timeout` / `timeoutMs` | Python seconds, TS milliseconds; Python defaults to 60 seconds; `0` removes the connection limit. |
| `request_timeout` / `requestTimeoutMs` | Python 2.37.1 streaming `run/connect` use `timeout` for opening and consuming the stream. |

`CommandResult` contains stdout, stderr and the exit code. Python `CommandHandle.wait()` raises `CommandExitException` on a nonzero exit; distinguish command failure from request timeout.

[Python SDK 2.37.1 reference](https://docs.e2b.dev/sdk-reference/python-sdk/v2.37.1/sandbox_sync)
