# Pause and Resume

> **Availability**
>
> Pause and resume is currently available only to allowlisted accounts. Complete allowlist enablement before calling `sandbox.pause()` or connecting to a paused Sandbox.

Pause lets you preserve Sandbox state for a period of time and continue later by reconnecting to the same Sandbox.

## Pause a Sandbox

Pause the current Sandbox:

```python
sandbox.pause()
```

TypeScript example:

```typescript
await sandbox.pause();
```

After a Sandbox is paused, it is no longer in an active running state. You can resume using it later by reconnecting to the existing Sandbox.

## Auto-resume on Connect

`Sandbox.connect(sandboxId)` can connect to an existing Sandbox. If the Sandbox is paused, it is automatically resumed when you connect.

```python
import os

from e2b_code_interpreter import Sandbox

sandbox = Sandbox.connect(
    sandbox_id,
    api_key=os.environ["E2B_API_KEY"],
    api_url=os.environ["E2B_API_URL"],
    domain=os.environ["E2B_DOMAIN"],
)
```

TypeScript example:

```typescript
const sandbox = await Sandbox.connect(sandboxId, {
  apiKey: process.env.E2B_API_KEY,
  apiUrl: process.env.E2B_API_URL,
  domain: process.env.E2B_DOMAIN,
});
```

## Recommendations

- Pause a Sandbox when a task needs to preserve context for a short interval between steps.
- After resuming, recheck long-lived connections, process state, and application state before proceeding.
- Pause is not the same as kill. When the task is complete, call `sandbox.kill()` to release resources.

### `POST /sandboxes/{sandboxID}/pause`



[Official contract](https://docs.e2b.dev/api-reference/sandboxes/pause-sandbox)

**Endpoint:** `POST /sandboxes/{sandboxID}/pause`

Servers: `https://api.e2b.app`.

Security (upstream OpenAPI): `[{"ApiKeyAuth": []}]`. Scheme details are provided in the linked official contract.

#### Request parameters

| Name | Location | Type | Required | Constraints | Description |
|---|---|---|---|---|---|
| sandboxID | path | string | yes | — | — |

#### Request body

Required: **no**.

##### application/json

| Field | Type / schema | Required | Constraints | Description |
|---|---|---|---|---|
| `memory` | boolean | no | default=true | Whether to capture a full memory snapshot. When false, only the filesystem is persisted and resuming the sandbox cold-boots (reboots) it from disk, losing in-memory state, running processes, and open connections. Resume it with an explicit request (connect or resume); auto-resume, which can be triggered by arbitrary traffic, refuses such a sandbox. Defaults to true. |

#### Responses

| Status | Description | Content type | Schema |
|---|---|---|---|
| 204 | The sandbox was paused successfully and can be resumed | none declared | — |
| 401 | Authentication error | application/json | Error |
| 404 | Not found | application/json | Error |
| 409 | Conflict | application/json | Error |
| 500 | Server error | application/json | Error |

### `POST /sandboxes/{sandboxID}/resume`



[Official contract](https://docs.e2b.dev/api-reference/sandboxes/resume-sandbox)

**Endpoint:** `POST /sandboxes/{sandboxID}/resume`

Servers: `https://api.e2b.app`.

Security (upstream OpenAPI): `[{"ApiKeyAuth": []}]`. Scheme details are provided in the linked official contract.

**Deprecated upstream operation.**

#### Request parameters

| Name | Location | Type | Required | Constraints | Description |
|---|---|---|---|---|---|
| sandboxID | path | string | yes | — | — |

#### Request body

Required: **no**.

##### application/json

| Field | Type / schema | Required | Constraints | Description |
|---|---|---|---|---|
| `timeout` | integer | no | default=15; minimum=0; format="int32" | Time to live for the sandbox in seconds. |
| `autoPause` | boolean | no | deprecated=true | Automatically pauses the sandbox after the timeout |
| `memory` | boolean | no | — | Defaults to true. When false, resume from disk state only: the sandbox cold-boots fresh and any memory in the snapshot is ignored, never modified or deleted. Disk state has crash-recovery semantics — writes not flushed before the pause may be lost. A no-op for snapshots that contain no memory. Rejected with an error in environments where this capability is not enabled, never silently downgraded to a memory restore. |

| 400 | Bad request | application/json | Error |
| 401 | Authentication error | application/json | Error |
| 404 | Not found | application/json | Error |
| 409 | Conflict | application/json | Error |
| 500 | Server error | application/json | Error |
| 503 | Service unavailable | application/json | Error |
| 504 | Backend timeout | application/json | Error |
