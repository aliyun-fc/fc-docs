# Metrics

Sandbox Metrics lets you inspect runtime metrics such as CPU and memory. FC Agent Sandbox supports sandbox metrics and currently returns data at 1-minute granularity.

SDK example:

```typescript
const metrics = await sandbox.getMetrics();
console.log(metrics);

const metricsById = await Sandbox.getMetrics(sandbox.sandboxId, {
  apiKey: process.env.E2B_API_KEY,
  apiUrl: process.env.E2B_API_URL,
  domain: process.env.E2B_DOMAIN,
});
console.log(metricsById);
```

Python example:

```python
metrics = sandbox.get_metrics()
print(metrics)

metrics_by_id = Sandbox.get_metrics(
    sandbox.sandbox_id,
    api_key=os.environ["E2B_API_KEY"],
    api_url=os.environ["E2B_API_URL"],
    domain=os.environ["E2B_DOMAIN"],
)
print(metrics_by_id)
```

CLI example:

```bash
e2b sandbox metrics <sandbox-id>
```

The response includes the sampling time, CPU usage and core count, and memory used and total. Disk and page-cache fields return placeholder values and should not be used for capacity decisions.

This capability is suitable for debugging, resource trend observation, and task troubleshooting. Use the Function Compute console, CloudMonitor, or Simple Log Service as the source of truth for billing, alerting, autoscaling, and capacity governance.

## HTTP request and response fields

The following protocol details were checked against the official E2B OpenAPI on 2026-09-08. Required properties apply to their containing object. FC support and differences follow the guidance on this page and the [compatibility inventory](../../07.Developer%20Reference/01.E2B%20SDK-compatible%20API%20List.md). ### `GET /sandboxes/{sandboxID}/metrics`



[Official contract](https://docs.e2b.dev/api-reference/sandboxes/get-sandbox-metrics)

**Endpoint:** `GET /sandboxes/{sandboxID}/metrics`

Servers: `https://api.e2b.app`.

Security (upstream OpenAPI): `[{"ApiKeyAuth": []}]`. Scheme details are provided in the linked official contract.

#### Request parameters

| Name | Location | Type | Required | Constraints | Description |
|---|---|---|---|---|---|
| sandboxID | path | string | yes | — | — |
| start | query | integer | no | minimum=0; format="int64" | Unix timestamp for the start of the interval, in seconds, for which the metrics are returned. |
| end | query | integer | no | minimum=0; format="int64" | Unix timestamp for the end of the interval, in seconds, for which the metrics are returned. |

#### Responses

| Status | Description | Content type | Schema |
|---|---|---|---|
| 200 | Successfully returned the sandbox metrics | application/json | array of SandboxMetric |
| 400 | Bad request | application/json | Error |
| 401 | Authentication error | application/json | Error |
| 404 | Not found | application/json | Error |
| 500 | Server error | application/json | Error |

#### Data structures

##### SandboxMetric

Metric entry with timestamp and line

| Field | Type / schema | Required | Constraints | Description |
|---|---|---|---|---|
| `timestamp` | string | yes | deprecated=true; format="date-time" | Timestamp of the metric entry |
| `timestampUnix` | integer | yes | format="int64" | Timestamp of the metric entry in Unix time (seconds since epoch) |
| `cpuCount` | integer | yes | format="int32" | Number of CPU cores |
| `cpuUsedPct` | number | yes | format="float" | CPU usage percentage |
| `memUsed` | integer | yes | format="int64" | Memory used in bytes |
| `memTotal` | integer | yes | format="int64" | Total memory in bytes |
| `memCache` | integer | yes | format="int64" | Cached memory (page cache) in bytes |
| `diskUsed` | integer | yes | format="int64" | Disk used in bytes |
| `diskTotal` | integer | yes | format="int64" | Total disk space in bytes |

##### Error

| Field | Type / schema | Required | Constraints | Description |
|---|---|---|---|---|
| `code` | integer | yes | format="int32" | Error code |
| `error_code` | string | no | — | Machine-readable semantic error code. Not a closed set; initial values: sandbox_capacity_unavailable, sandbox_placement_timeout, sandbox_no_compatible_node, sandbox_create_failed, internal_server_error. |
| `message` | string | yes | — | Error |

[Official contract](https://docs.e2b.dev/api-reference/sandboxes/list-sandbox-metrics)

**Endpoint:** `GET /sandboxes/metrics`

Servers: `https://api.e2b.app`.

Security (upstream OpenAPI): `[{"ApiKeyAuth": []}]`. Scheme details are provided in the linked official contract.

#### Request parameters

| Name | Location | Type | Required | Constraints | Description |
|---|---|---|---|---|---|
| sandbox_ids | query | array of string | yes | maxItems=100; uniqueItems=true | Comma-separated list of sandbox IDs to get metrics for |
