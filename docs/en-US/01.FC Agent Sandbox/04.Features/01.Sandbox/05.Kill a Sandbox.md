# Kill a Sandbox

Killing a Sandbox releases its resources. Explicitly kill the Sandbox when a task finishes, encounters an unrecoverable error, or exceeds the time your application is willing to wait.

## Kill the Current Sandbox

```typescript
await sandbox.kill();
```

Python example:

```python
sandbox.kill()
```

Release resources in `finally`:

```typescript
const sandbox = await Sandbox.create("code-interpreter-v1", {
  apiKey: process.env.E2B_API_KEY,
  apiUrl: process.env.E2B_API_URL,
  domain: process.env.E2B_DOMAIN,
});

try {
  await sandbox.commands.run("npm test");
} finally {
  await sandbox.kill();
}
```

Python example:

```python
sandbox = Sandbox.create(
    template="code-interpreter-v1",
    api_key=os.environ["E2B_API_KEY"],
    api_url=os.environ["E2B_API_URL"],
    domain=os.environ["E2B_DOMAIN"],
)

try:
    sandbox.commands.run("python3 -m pytest")
finally:
    sandbox.kill()
```

## Difference from pause

`kill()` ends the Sandbox lifecycle, while `pause()` suspends the Sandbox so it can be resumed later. After a Sandbox is killed, you cannot return to the same runtime state with `Sandbox.connect()`.

If the task only needs to wait briefly for the user to continue, use [Pause and Resume](06.Pause%20and%20Resume.md). If the task is complete, kill the Sandbox.

### `DELETE /sandboxes/{sandboxID}`



[Official contract](https://docs.e2b.dev/api-reference/sandboxes/delete-sandbox)

**Endpoint:** `DELETE /sandboxes/{sandboxID}`

Servers: `https://api.e2b.app`.

Security (upstream OpenAPI): `[{"ApiKeyAuth": []}]`. Scheme details are provided in the linked official contract.

#### Request parameters

| Name | Location | Type | Required | Constraints | Description |
|---|---|---|---|---|---|
| sandboxID | path | string | yes | — | — |

#### Responses

| Status | Description | Content type | Schema |
|---|---|---|---|
| 204 | The sandbox was killed successfully | none declared | — |
| 401 | Authentication error | application/json | Error |
| 404 | Not found | application/json | Error |
| 500 | Server error | application/json | Error |

#### Data structures

##### Error

| Field | Type / schema | Required | Constraints | Description |
|---|---|---|---|---|
| `code` | integer | yes | format="int32" | Error code |
| `error_code` | string | no | — | Machine-readable semantic error code. Not a closed set; initial values: sandbox_capacity_unavailable, sandbox_placement_timeout, sandbox_no_compatible_node, sandbox_create_failed, internal_server_error. |
| `message` | string | yes | — | Error |
