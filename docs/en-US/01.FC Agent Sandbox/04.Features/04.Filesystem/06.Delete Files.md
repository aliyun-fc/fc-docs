# Delete Files

Deleting files is useful for cleaning up temporary inputs, caches, and generated outputs. It only affects the filesystem inside the current sandbox.

## Delete a file or directory

Python example:

```python
sandbox.files.remove("/tmp/project/output.log")
```

TypeScript example:

```typescript
await sandbox.files.remove("/tmp/project/output.log");
```

Before deleting a directory, confirm the path to avoid removing the entire workspace by mistake:

Python example:

```python
exists = sandbox.files.exists("/tmp/project/output.log")

if exists:
    sandbox.files.remove("/tmp/project/output.log")
```

TypeScript example:

```typescript
const exists = await sandbox.files.exists("/tmp/project/output.log");

if (exists) {
  await sandbox.files.remove("/tmp/project/output.log");
}
```

## Recommendations

If the full sandbox will be terminated when the task ends, you usually do not need to delete temporary files one by one. Proactive cleanup is mainly useful for long-lived sandboxes or when multiple tasks run in the same sandbox.

### `POST /filesystem.Filesystem/Remove`



[Official contract](https://docs.e2b.dev/api-reference/filesystem/remove)

**Endpoint:** `POST /filesystem.Filesystem/Remove`

Servers: `https://sandbox.{domain}`.

Security (upstream OpenAPI): `[{"SandboxAccessTokenAuth": [], "SandboxUserAuth": []}]`. Scheme details are provided in the linked official contract.

#### Request parameters

| Name | Location | Type | Required | Constraints | Description |
|---|---|---|---|---|---|
| E2b-Sandbox-Id | header | string | yes | — | Identifier of the target sandbox. Routes the request to that sandbox's envd over the shared sandbox host. |
| E2b-Sandbox-Port | header | integer | yes | default=49983 | Port envd listens on inside the sandbox (default 49983). |
| Connect-Protocol-Version | header | connect-protocol-version | yes | const=1 | Define the version of the Connect protocol |
| Connect-Timeout-Ms | header | connect-timeout-header | no | — | Define the timeout, in ms |

#### Request body

Required: **yes**.

##### application/json

| Field | Type / schema | Required | Constraints | Description |
|---|---|---|---|---|
| `path` | string | no | — | — |

#### Responses

| Status | Description | Content type | Schema |
|---|---|---|---|
| 200 | Success | application/json | filesystem.RemoveResponse |
| 502 | Sandbox not found | application/json | object |

#### Data structures

##### connect-protocol-version

Define the version of the Connect protocol

Type: `number`. Constraints: const=1. See the official contract linked above.

##### connect-timeout-header

Define the timeout, in ms

Type: `number`. Constraints: —. See the official contract linked above.

##### filesystem.RemoveRequest

| Field | Type / schema | Required | Constraints | Description |
|---|---|---|---|---|

##### filesystem.RemoveResponse

Type: `object`. Constraints: —. See the official contract linked above.
